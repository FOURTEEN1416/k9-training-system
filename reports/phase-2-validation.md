## 12. 关键技术成果

1. **数据飞轮闭环**：标注 → 微调 → 部署全流程 API 化（4 端点 + LS 集成）
2. **16 类行为规则引擎**：P0 8 类 + P1 8 类（追踪/示警坐/示警卧/扑咬/押解/障碍穿越/返回/警戒）
3. **USPCA 5 维评分卡**：标准对齐（准确度 0.30 + 延迟 0.20 + 保持 0.20 + 搜索效率 0.15 + 注意力 0.15）
4. **1.2f 数据源问题彻底解决**：AK 域不匹配诊断 + dog-pose val 同域验证
5. **ONNX 部署 bug 修复**：显式 `task='pose'` 避免 ONNX 回退 detect
6. **端到端延迟优化**：0.33x（比 Phase 1 的 0.5x 更优）
