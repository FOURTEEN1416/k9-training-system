## 1. 项目概述

**项目名称**：工作犬训练机器视觉识别系统（K9 Training Vision System）

**一句话定位**：将工作犬训练评估从"人工观察+经验记录"升级为"视频输入 → 姿态检测 → 行为识别 → 标准化评分报告"的端到端闭环，**双场景覆盖幼犬选育 + 科目测评**，本地部署、无云依赖。

**核心价值**（来自用户原话）：
- 工作犬选苗标准像挑"原始狼"——食物欲望/玩具欲望/胆量捕猎本能
- 解决人工观察主观性强、复盘困难、训练数据难沉淀的问题
- 帮训导员科学"看清"哪条狗是好苗子、哪个动作练到位了
- 服务公安、海关、消防及社会相关行业

## 2. 目标用户与场景

| 用户角色 | 核心场景 | 核心诉求 |
|---------|---------|---------|
| 公安警犬基地 | 幼犬选育 + 服从科目训练评估 | 选苗量化、训练档案、标准化评分 |
| 海关缉私犬队 | 搜索作业评估 + 选育 | 搜索效率量化、选苗依据 |
| 消防搜救犬队 | 搜救能力评估 + 选育 | 复杂环境行为识别 |
| 工作犬训练机构 | 日常训练记录 + 幼犬选育 | 数据沉淀、趋势分析 |
| 犬行为科研单位 | 行为学研究 | 行为数据集、统计分析 |

## 3. 核心用户动作与旅程

**核心动作**：训导员上传训练视频 → 系统自动识别行为（选育信号 / 科目动作）→ 生成标准化评分报告 → 训导员复盘改进

**用户旅程**：
1. 训导员在训练场录制视频（食物欲望测试 / 玩具测试 / 胆量测试 / 服从科目）
2. 上传视频到系统
3. 系统自动执行：姿态检测 → 行为信号提取 → 场景分类 → 评分
4. 生成评分报告（PDF + 可视化标注视频）
5. 训导员查看报告，对比历史数据，调整训练方案
6. 管理层查看基地级统计数据

## 4. MVP 范围（3-4 周，单人全职）

**Phase 1 MVP 交付**（3-4 周）：
- YOLO26-pose 24 关键点姿态检测（✅ Phase 1.0 已完成 best.pt）
- **幼犬选育场景**：食物欲望 + 玩具欲望 + 胆量 3 维自动评分（原型级）
- **科目测评场景**：规则引擎 8 类基础行为 + 5 维评分
- **YAML 配置化评分引擎**：训导员可动态调节阈值/权重
- FastAPI 后端 + Vue 前端 + PDF 报告端到端
- 基于公开数据集（DogMo / InterPet4D）评估，无需基地视频

**学术副产物**（不阻塞主交付）：
- 可解释 AI 评分卡 + 工作犬行为识别
- 目标：ACM MM Application Track / AAAI Application Track
- 时间：Phase 1 完成后整理

## 5. 非目标（显式排除）

- ❌ 不做云端部署（Phase 1-3 严格本地化）
- ❌ 不做实时推理（Phase 1 为离线视频处理）
- ❌ 不做犬只个体识别（Phase 1 不区分具体犬只）
- ❌ 不做训导员动作识别（仅识别犬行为）
- ❌ 不做商业 LLM API 依赖（Phase 4 LLM 解释器优先开源/本地）
- ❌ 不做基地视频采集（用户拿不到，用公开数据）
- ❌ 不做 GA-T 原文对齐（拿不到原文，用公开数据 + 动态可配规则）

**确认的下一阶段能力（Phase 2-3）**：

**确认的远期能力（Phase 4，按需触发）**：

**必须不阻塞项**：

- 本地部署能力（无云依赖）

## 7. 数据与业务对象

**核心业务对象**：
- `dogs` — 犬只档案（品种、年龄、训练阶段）
- `videos` — 训练视频（路径、时长、拍摄场景、测试类型）
- `keypoints` — 24 关键点姿态序列（帧级）
- `behaviors` — 行为识别结果（类别、时间区间、置信度）
- `scores` — 评分结果（多维度，YAML 配置驱动）
- `models` — 模型版本（类型、权重路径、指标）
- `handlers` — 训导员档案
- `training_sessions` — 训练会话记录
- `scoring_configs` — 评分卡 YAML 配置（版本化）

**双场景行为/信号分类**：

**幼犬选育场景**（3 维信号）：
- 食物欲望：approach_latency, approach_speed, sniff_duration
- 玩具欲望：chase_latency, chase_speed, hold_duration
- 胆量：retreat_distance, freeze_duration, recovery_time

**科目测评场景**（8 类基础行为 + 5 维评分）：
- P0 基础 8 类：坐/卧/立/随行/坐立/停留/叫/咬
- 5 维评分：准确度/延迟/保持/注意力/步态

## 8. 产品形态判断

**初始形态**：本地部署的 Web 应用（FastAPI 后端 + Vue 前端）
- Phase 1：单机本地部署（Windows 优先，3-4 周原型级）
- Phase 2+：基地可用级（错误恢复 + 部署文档 + 用户体验优化）
- Phase 3+：支持 Jetson Orin Nano Super 边缘部署

## 9. 初始技术路线判断

> 最终技术选型见 `technical-selection.md`

**候选基线**（基于调研）：
- 姿态引擎：YOLO26-pose（24 关键点，✅ best.pt 已微调）
- 物体检测：YOLO26 默认 COCO 80 类（球/玩具/食物子集）
- 行为识别：规则引擎（科目测评）+ 信号提取器（选育场景）
- 评分引擎：自研轻量 YAML 配置化引擎（约 200 行）
- 后端：FastAPI + Celery + Redis
- 数据库：PostgreSQL 17 + pgvector
- 前端：Vue 3 + Naive UI + ECharts
- 部署：原生 Python（Windows 优先）

## 11. 差异化与长期方向

**差异化**：
- **双场景覆盖**：选育（蓝海）+ 测评（红海），目前市面仅单一场景
- **可解释评分**：YAML 评分卡，每条评分给出命中规则 + 标签
- **数据隐私**：完全本地部署，适合公安/海关场景
- **端到端**：视频 → 评分报告，无需人工干预

**长期方向**：
- 多基地部署 + 数据联邦
- 基地合作后真实数据采集 + 模型精化
- 商业化定制（白标 + 模型定制训练服务）
- 学术副产物（顶会应用 Track + 数据集 + 基准）
