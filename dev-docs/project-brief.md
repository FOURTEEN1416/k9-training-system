# Project Brief — 工作犬训练机器视觉识别系统

## 1. 项目概述

**项目名称**：工作犬训练机器视觉识别系统

**一句话定位**：将工作犬训练评估从"人工观察+经验记录"升级为"视频输入 → 姿态检测 → 行为识别 → 标准化评分报告"的端到端闭环，本地部署、无云依赖。

**核心价值**：
- 降低工作犬失败率（当前 >50%，单犬训练成本 >$12,000）
- 消除人工评估主观性，沉淀训练数据
- 填补全球无完整全科目自动警犬评估系统的市场空白

## 2. 目标用户与场景

| 用户角色 | 场景 | 核心诉求 |
|---------|------|---------|
| 公安警犬基地 | 服从科目训练评估 | 标准化评分、训练档案 |
| 海关缉私犬队 | 搜索作业评估 | 搜索效率量化、路径分析 |
| 消防搜救犬队 | 搜救能力评估 | 复杂环境行为识别 |
| 工作犬训练机构 | 日常训练记录 | 数据沉淀、趋势分析 |
| 犬行为科研单位 | 行为学研究 | 行为数据集、统计分析 |

## 3. 核心用户动作与旅程

**核心动作**：训导员上传训练视频 → 系统自动识别行为 → 生成标准化评分报告 → 训导员复盘改进

**用户旅程**：
1. 训导员在训练场录制视频（或多摄像头实时流）
2. 上传视频到系统（或接入 RTSP 流）
3. 系统自动执行：姿态检测 → 行为分类 → 评分
4. 生成评分报告（PDF/CSV）+ 可视化标注视频
5. 训导员查看报告，对比历史数据，调整训练方案
6. 管理层查看基地级统计数据

## 4. MVP 范围

**Phase 1 MVP 交付**（4-6 周）：
- YOLO26-pose 24 关键点姿态检测
- 规则引擎 + PoseC3D 行为分类（8 类基础行为 P0）
- GA-T 标准 3 维评分（准确度/延迟/保持时长）
- FastAPI 后端 + Vue 前端原型
- 1 段训练视频 → 评分报告 PDF 端到端验证

## 5. 非目标（显式排除）

- ❌ 不做云端部署（Phase 1-3 严格本地化）
- ❌ 不做实时推理（Phase 1 为离线视频处理）
- ❌ 不做犬只个体识别（Phase 1 不区分具体犬只）
- ❌ 不做训导员动作识别（仅识别犬行为）
- ❌ 不做商业 LLM API 依赖（Phase 4 LLM 解释器优先开源/本地）

## 6. 确认的演进边界

**当前交付（Phase 0-1）**：
- 项目基础设施 + MVP 端到端闭环

**确认的下一阶段能力（Phase 2-3）**：
- 数据飞轮 + 16-22 种行为 + ST-GCN+BC + 多犬追踪 + 3D 姿态 + FCI-IGP

**确认的远期能力（Phase 4，按需触发）**：
- LLM 行为解释器 / Transformer-Mamba 长序列 / RL 评分优化

**必须不阻塞项**：
- 三大标准兼容（GA-T / USPCA / FCI-IGP）
- 本地部署能力（无云依赖）

**投机性想法（不影响当前架构）**：
- 多模态融合（视觉+IMU+音频）—— 未确认是否进入 Phase 4
- 神经组合优化搜索路径评估 —— 未确认是否进入 Phase 4
- 3D 姿态自研 —— 仅当现有 3DDogs/DigiDogs 不满足时

## 7. 数据与业务对象

**核心业务对象**：
- `dogs` — 犬只档案（品种、年龄、训练阶段）
- `videos` — 训练视频（路径、时长、拍摄场景）
- `keypoints` — 24 关键点姿态序列（帧级）
- `behaviors` — 行为识别结果（类别、时间区间、置信度）
- `scores` — 评分结果（7 维度）
- `models` — 模型版本（类型、权重路径、指标）
- `behavior_vectors` — 行为向量（pgvector，用于相似检索）
- `handlers` — 训导员档案
- `training_sessions` — 训练会话记录

**22 种行为分类**（详见 `research/RESEARCH_STANDARDS.md`）：
- P0 基础姿态 8 种（坐/卧/立/走/跑/跳/停/转）
- P1 训练专项 8 种（搜索/指示/拾取/跳跃障碍/攀爬/匍匐/吠叫/安静）
- P2 高级评估 6 种（拒绝食物/护卫/解救/追踪/鉴别/复杂搜索）

## 8. 产品形态判断

**初始形态**：本地部署的 Web 应用（FastAPI 后端 + Vue 前端）
- Phase 1：单机本地部署（Windows 优先）
- Phase 3+：支持 Jetson Orin Nano Super 边缘部署

## 9. 初始技术路线判断

> ⚠️ 本节为初始判断，最终技术选型见 `technical-selection.md`

**候选基线**（基于调研）：
- 姿态引擎：YOLO26-pose（24 关键点，NMS-Free）
- 行为分类：规则 → PoseC3D → ST-GCN+BC（三阶段递进）
- 后端：FastAPI + Celery + Redis
- 数据库：PostgreSQL 15 + pgvector
- 前端：Vue 3 + Naive UI + ECharts
- 部署：原生 Python（Windows 优先）

## 10. 同类产品参考

> 详见 `research/RESEARCH_OPENSOURCE.md` 与 `research/RESEARCH_COMMERCIAL.md`

**可直接复用**：
- **ASBAR 框架**（[MitchFuchs/asbar](https://github.com/MitchFuchs/asbar)）：DLC→PoseC3D 管道，最直接代码基础
- **MMAction2**：PoseC3D/ST-GCN 官方实现
- **Ultralytics Dog-Pose 数据集**：6,773 训练 / 1,703 测试，24 关键点

**学术参考**：
- **BCST-GCN 2026**：94.43% NTU RGB+D，Phase 3 升级方向
- **NC State IMU+AI**：导盲犬学校 10 年部署经验
- **SimBA**：90.5-96.4% 行为识别

**学习要点**：
- ASBAR 的 DLC→PoseC3D 管道可改造为 YOLO26→PoseC3D
- NC State 的 IMU+AI 多模态思路（Phase 4 备选）

**不复制要点**：
- ASBAR 用 DeepLabCut（DLC），我们用 YOLO26-pose（更轻、更快）
- 不复制 SimBA 的实验室行为分类逻辑（工作犬场景不同）

**差异化**：
- 全球首个完整全科目自动警犬评估系统
- 三大标准兼容（GA-T / USPCA / FCI-IGP）
- 本地部署、无云依赖（数据隐私）

## 11. 差异化与长期方向

**差异化**：
- 标准化：兼容三大国际标准，自动化率 45-60%
- 数据隐私：完全本地部署，适合公安/海关场景
- 端到端：视频 → 评分报告，无需人工干预

**长期方向**：
- 多基地部署 + 数据联邦
- 幼犬选育评估
- 商业化定制（白标 + 模型定制训练服务）
