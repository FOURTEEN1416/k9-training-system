## 1. 项目概述

**项目性质**：**学术研究项目**，产品系统（K9 Training Vision System）作为方法验证载体和副产物。
> ⚠️ **2026-08-23 更新（ADR 0013）**：研究线（基座愿景 + PR/IJCV 论文 + P0 数据解阻）已移交独立仓库 `D:\Desktop\psd-framework`。本仓库定位收窄为**产品验证平台**——④产品系统 + ⑤Phase 4 产品升级在此推进，并继续作为研究方法的验证载体。本文档其余章节保留历史立项口径，涉及研究线的表述以 psd-framework 仓库 truth 为准。

**研究方向**：物理-语义解耦的低资源动物行为识别框架，适应动态演化评估标准。

**核心创新候选**：在当前文献检索范围内，拟将图像域小样本伪标签方法（姚青 JIA：VFM 骨干 + 锚点学习 + 聚类 + 伪标签）迁移到**时序骨架域**，结合 AimCLR（AAAI 2022）+ SMQ（ICCV 2025）+ TCL（CVPR 2021）形成完整技术栈，解决低资源场景下动物行为识别的数据瓶颈；“首次”主张待论文阶段继续核验。

**产品价值**：将工作犬训练评估从"人工观察+经验记录"升级为"视频输入 → 姿态检测 → 行为识别 → 标准化评分报告"的端到端闭环，作为研究方法的验证平台。

**论文定位**：
- **Title**：A Physics-Semantics Decoupled Framework for Low-Resource Animal Behavior Recognition under Evolving Evaluation Criteria
- **目标期刊**：Pattern Recognition（IF≈8.0）/ IJCV
- **核心创新**：VFM + 锚点 + 聚类 + 伪标签（姚青 JIA）从图像域迁移到时序骨架域 + 物理-语义解耦架构

**核心价值**（学术层面）：
- 在当前检索范围内尚未发现完全相同的图像域方法到时序骨架域迁移组合，拟通过实验验证其有效性
- 物理-语义解耦架构：物理层（姿态骨架）与语义层（行为标签）分离，适应评估标准动态演化
- 低资源场景下动物行为识别的新范式：规则种子 → 自监督预训练 → 无监督分割 → 半监督自训练 → 主动学习

**产品价值**（验证层面）：
- 工作犬选苗标准像挑"原始狼"——食物欲望/玩具欲望/胆量捕猎本能
- 解决人工观察主观性强、复盘困难、训练数据难沉淀的问题
- 帮训导员科学"看清"哪条狗是好苗子、哪个动作练到位了

## 3. 核心用户动作与旅程

**核心动作**：训导员上传训练视频 → 系统自动识别行为（选育信号 / 科目动作）→ 生成标准化评分报告 → 训导员复盘改进

**用户旅程**：
1. 训导员在训练场录制视频（食物欲望测试 / 玩具测试 / 胆量测试 / 服从科目）
2. 上传视频到系统
3. 系统自动执行：姿态检测 → 行为信号提取 → 场景分类 → 评分
4. 生成评分报告（PDF + 可视化标注视频）
5. 训导员查看报告，对比历史数据，调整训练方案
6. 管理层查看基地级统计数据

## 4. 研究范围（当前阶段）

**P0 数据解阻（3-4 周）—— 核心研究交付**：
- ✅ **SMQ（ICCV 2025）**：骨架运动词向量量化，无监督时序分割，输入 (T,24,3) 直接兼容
- ✅ **AimCLR（AAAI 2022，MIT 许可）**：骨架自监督对比学习，NTU 60 达 79.18%
- ✅ **TCL（CVPR 2021）**：时序对比学习，10% 标注→82.7% 接近全监督 88.6%
- 🔥 **姚青 JIA 方法迁移（核心创新）**：VFM 骨干 + 锚点学习 + 聚类 + 伪标签，从图像域迁移到时序骨架域
- 🔥 规则引擎粗标（种子）→ AimCLR 预训练 → SMQ 分割 → TCL 自训练 → 主动学习 100-200 标注 → ST-GCN+BC ≥85%

**产品系统（Phase 1-3，已完成——作为验证平台）**：
- YOLO26-pose 24 关键点姿态检测 + 双场景评分引擎 + FCI-IGP 评分卡
- 端到端闭环：视频 → 姿态 → 行为 → 评分报告
- 用于验证上述研究方法在实际场景中的有效性

## 5. 非目标（显式排除）

- ❌ 不做云端部署（Phase 1-3 严格本地化）
- ❌ 不做实时推理（Phase 1 为离线视频处理）
- ❌ 不做犬只个体识别（Phase 1 不区分具体犬只）
- ❌ 不做训导员动作识别（仅识别犬行为）
- ⚠️ 商业 LLM API 依赖：**实验室阶段豁免**（Agnes API，用户确认 2026-08-19，见 ADR 0011 v1.1），**实用阶段强制本地大模型**（数据不出本地，列入 HANDOVER P1 跟踪）
- ❌ 不做基地视频采集（用户拿不到，用公开数据）
- ❌ 不做 GA-T 原文对齐（拿不到原文，用公开数据 + 动态可配规则）

## 7. 数据与业务对象

**核心业务对象**：
- `dogs` — 犬只档案（品种、年龄、训练阶段）
- `videos` — 训练视频（路径、时长、拍摄场景、测试类型）
- `keypoints` — 24 关键点姿态序列（帧级）
- `behaviors` — 行为识别结果（类别、时间区间、置信度）
- `scores` — 评分结果（多维度，YAML 配置驱动）
- `models` — 模型版本（类型、权重路径、指标）
- `handlers` — 训导员档案
- `training_sessions` — 训练会话记录
- `scoring_configs` — 评分卡 YAML 配置（版本化）

**双场景行为/信号分类**：

**幼犬选育场景**（3 维信号）：
- 食物欲望：approach_latency, approach_speed, sniff_duration
- 玩具欲望：chase_latency, chase_speed, hold_duration
- 胆量：retreat_distance, freeze_duration, recovery_time

**科目测评场景**（8 类基础行为 + 5 维评分）：
- P0 基础 8 类：坐/卧/立/随行/坐立/停留/叫/咬
- 5 维评分：准确度/延迟/保持/注意力/步态

## 11. 差异化与长期方向

**差异化（学术层面）**：
- 🔥 **拟将图像域 VFM+锚点+聚类+伪标签方法（姚青 JIA）迁移到时序骨架域**；“首次”与“无人做过”仅作为待核验论文主张
- 物理-语义解耦架构：评估标准变化时仅需修改语义层，物理层不变
- 三个高引用工作（AimCLR AAAI 2022 / SMQ ICCV 2025 / TCL CVPR 2021）的首次系统集成

**产品差异化**（验证层面）：
- 双场景覆盖：选育（蓝海）+ 测评（红海），目前市面仅单一场景
- 可解释评分：YAML 评分卡，每条评分给出命中规则 + 标签
- 数据隐私：完全本地部署，适合公安/海关场景
- 端到端：视频 → 评分报告，无需人工干预

**长期方向**：
- **学术**：Pattern Recognition → IJCV → TPAMI 进阶
- **学术**：开源数据集（InterPet4D + AK 犬科处理版）发布
- **产品**：多基地部署 + 数据联邦（作为学术方法的验证平台）
- **产品**：商业化定制（白标 + 模型定制训练服务）
