## 2. 关键方法论发现（按重要性排序）

### 发现 1：SMQ（ICCV 2025）—— 骨架无监督时序分割，与您的方案 A 高度同构

**SMQ = Skeleton Motion Words**，核心思想：
- 骨架序列 → 膨胀 TCN 编码 → 向量量化（VQ）→ 离散"运动词" → 解码重建
- 运动词等同于 keypoint-MoSeq 的 syllables，但更先进（VQ 端到端学习）
- 输出：帧级动作分割标签（无监督！）

**对本项目的意义**：
- 输入 (T, 24, 3) 骨架序列直接兼容
- 无监督产出帧级标签 ≈ 您的方案 A 的"物理运动表征基座"
- 与 keypoint-MoSeq 对比：端到端 VQ 学习更稳定，类覆盖更全面

### 发现 2：AimCLR（AAAI 2022，MIT 许可）—— 骨架自监督预训练，可直接用于本项目

**AimCLR** 在 NTU 60 xsub 上 **79.18%**（无监督，线性评估），MIT 许可，代码完整。

**对本项目的意义**：
- 可在 ST-GCN++ 主干上做自监督预训练（利用 682 无标签骨架序列）
- 预训练后 + 少量标注（50-100）微调，预期可达 ≥85%
- 与现有的 pyskl + ST-GCN 管线完全兼容

### 发现 3：TCL（CVPR 2021）—— 半监督时序对比，10% 标注接近全监督

**TCL** 在 UCF-101 上仅 10% 标注即达 82.7%（全监督 88.6%）。

**对本项目的意义**：
- 方案 B 的核心方法论支撑：少量标注 + 大量无标注 = 高质量模型
- 时序对比损失天然适合动作边界检测

### 发现 4：姚青 JIA 方法与本项目的映射

姚青方法 = **VFM 特征 + 少量锚点 + 自监督聚类伪标签 + 置信度筛选**。

本项目迁移方案：
- **VFM 特征** → SMQ VQ 骨架嵌入 / AimCLR 对比学习特征（替代图像域 VFM）
- **少量锚点** → 规则引擎高置信样本 + 20-50 人工黄金样本
- **自监督聚类** → SMQ 运动词聚类 / TCL 时序对比
- **置信度筛选** → 熵阈值 + 主动学习采样

**核心创新**：将姚青的静态图像域方法**迁移到时序骨架域**，这是无人做过的。

## 3. 您的构想：学术定位与可行性分析
