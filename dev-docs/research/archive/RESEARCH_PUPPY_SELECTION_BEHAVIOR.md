## 0. 调研目标

回答三个问题：
1. 工作犬选苗/选育的标准流程是什么？训导员判定"高/中/低"的依据是什么？
2. 这些行为学概念（食物欲望/玩具欲望/胆量）能否被 CV 识别？识别什么具体信号？
3. 3-4 周内做"自动识别反应"原型的可行路径是什么？

## 1. 行业标准流程

### 1.1 美国 K9 选拔 12 步测试法（专业机构）

来源：美国某知名训犬机构搜爆犬挑选流程（[昆明警犬基地技术论文](http://www.kmjqjd.com/FWD_article.asp?ArticleID=279)）。

| 编号 | 测试 | 场景 | 评估能力 |
|------|------|------|---------|
| TEST1 | 物品欲望 | 户外草地，盆中 4-5 玩具倒出 | 玩具/猎物欲望 |
| TEST2 | 抗干扰 | 球吸引注意时背后敲击 | 注意力稳定性 |
| TEST3 | 搜索 | 抛物 10-50m 草地 10-20cm 深度 | 动力/专注/嗅觉/返回意愿 |
| TEST4 | 楼梯 | 钢架楼梯 20 阶窄梯 | 胆量/攀爬/学习能力 |
| TEST5 | 陌生人群适应 | 3-4 人靠近抚摸 | 社交性 |
| TEST6 | 意外反应 | 机关释放沙袋/铁板 | 胆量/抗压 |
| TEST7 | 室内搜索 | 柜桌木架塑料布平衡板 | 环境适应/搜索 |
| TEST8 | 黑屋 | 双隔间抛物 | 黑暗环境作业 |
| TEST9 | 枪声 | 散弹枪 20-30m | 胆量/抑制行为 |
| TEST10 | 环境适应 | 农机商场 | 复杂环境 |
| TEST11 | 室内搜索（商场） | 藏找胶球 | 嗅寻动力 |
| TEST12 | 超市 | 孩子声响摇晃设备 | 综合适应 |

### 1.2 中国警犬基地选拔标准

来源：惠水县公安局警犬中队、山东省公安厅警犬训练基地、南宁铁路公安局警犬繁育训练基地（[央广网](https://www.cnr.cn/gz/hezuo/20240207/t20240207_526588427.shtml)、[齐鲁晚报](http://www.sd.xinhuanet.com/20240315/7ae30a1ed28d4fbab31b484088a39d2a/c.html)、[中国新闻网](https://m.yunnan.cn/system/2023/02/15/032468941.shtml)）。

**核心维度**（5 项）：
1. **胆量** —— 不怕困难、无所畏惧
2. **兴奋及稳定程度** —— 静如处子动如脱兔
3. **衔取欲望** —— 物品动力
4. **物品动力** —— 玩具/猎物欲望
5. **食物动力** —— 对食物的渴望程度

**幼训测试维度**（4 项）：
1. 食物动力
2. 猎捕动力
3. 胆量
4. 抗压能力

**幼训考核**（6 月龄第一次入警考试）：
- 体能、胆量、衔取欲、占有欲、搜索欲 5 项
- 评分：60-79 基本合格，80+ 合格，59- 淘汰

### 1.3 国际通用 PAT 评分体系

Puppy Aptitude Test（PAT）7 维度（[Jianshu 综述](https://www.jianshu.com/p/93df2b67db53)）：
1. 追随性（Following）
2. 服从性（Obedience）
3. 敏感度（Sensitivity）
4. 探索欲（Exploration）
5. 支配性（Dominance）
6. 抗压能力（Stress Tolerance）
7. 人互动意愿（Human Interaction）

## 2. CV 可识别性分析

### 2.1 食物欲望测试的可识别信号

**测试方法**（[yicheng.vso.com.cn](https://yicheng.vso.com.cn/225951.html)）：将食物放在犬面前，观察反应。

**可 CV 识别的客观信号**：
| 信号 | 检测方式 | 难度 |
|------|---------|------|
| 接近速度 | 姿态关键点轨迹追踪 | 易 |
| 扑向食物 | 关键点速度突变 + 方向 | 中 |
| 等待/克制 | 静止时长 + 姿态稳定性 | 中 |
| 嗅闻时长 | 头部低倾姿态持续 | 易 |
| 注意力焦点 | 头部朝向（食物 vs 环境） | 中 |

**评分映射**：
- 高分：立即扑向食物（速度 > X m/s，< 1s 反应）
- 中分：嗅闻后缓慢接近（1-3s 反应）
- 低分：忽略食物（> 5s 无反应）

### 2.2 玩具/猎物欲望测试的可识别信号

**测试方法**：抛球/咬绳，观察追逐/咬住/不松口。

**可 CV 识别的客观信号**：
| 信号 | 检测方式 | 难度 |
|------|---------|------|
| 追逐启动延迟 | 球离手 → 犬启动时间 | 易 |
| 追逐速度 | 关键点速度 | 易 |
| 咬住动作 | 头部 + 物体重合 | 中 |
| 持续咬合时长 | 物体在口部持续时长 | 中 |
| 返回意愿 | 衔回速度 | 易 |

### 2.3 胆量测试的可识别信号

**测试方法**：枪声/黑屋/陌生物体，观察退缩/僵化/恢复。

**可 CV 识别的客观信号**：
| 信号 | 检测方式 | 难度 |
|------|---------|------|
| 退缩距离 | 关键点位移 | 易 |
| 僵化时长 | 关键点速度归零持续 | 中 |
| 恢复时间 | 恢复正常活动时长 | 中 |
| 探索行为 | 主动接近陌生物体 | 中 |
| 警觉姿态 | 头部高扬 + 耳朵前倾 | 难（需 24 关键点） |

## 3. 3-4 周可行性评估

### 3.1 技术路径

```
YOLO26-pose（已微调 best.pt）
   ↓ 24 关键点 + 检测框
行为信号提取器（规则引擎）
   ↓ 速度/距离/静止时长/朝向
场景分类器
   ↓ 食物/玩具/胆量
评分映射（YAML 配置）
   ↓ 高/中/低 + 数值化
报告生成
```

### 3.2 可行性矩阵

| 模块 | 现成度 | 3-4 周可达 | 风险 |
|------|--------|-----------|------|
| 姿态检测 | ✅ best.pt 已有 | ✅ | 低 |
| 物体检测（食物/玩具） | ⚠️ 需微调或 COCO 类别 | ✅（用 COCO 球类+食物类） | 中 |
| 行为信号提取 | ⚠️ 规则需调 | ✅ | 中 |
| 评分映射 | ✅ YAML 配置 | ✅ | 低 |
| 端到端集成 | ⚠️ 需联调 | ✅ | 中 |

### 3.3 关键限制

1. **原型级 ≠ 生产级**：3-4 周原型只能在受控环境（固定相机/良好光照/单一犬只）工作
2. **物体检测依赖 COCO**：食物种类繁多，3-4 周内无法训练专用检测器，只能用 COCO 80 类的子集
3. **评分规则需基地校准**：YAML 配置初始值靠公开资料，需基地反馈迭代

## 5. 推荐方案

### 5.1 选育场景优先级

P0（3-4 周必做）：
- 食物欲望测试（信号最易识别）
- 玩具欲望测试（球类检测现成）

P1（如时间允许）：
- 胆量测试（声响 + 陌生物体）

P2（Phase 2）：
- 抗干扰、搜索、楼梯、黑屋等复杂场景

### 5.2 评分规则可配置化

采用 YAML 评分卡（详见 [RESEARCH_SCORING_RULE_ENGINE.md](./RESEARCH_SCORING_RULE_ENGINE.md)）：

```yaml
scoring_engine:
  name: "幼犬选育评分"
  dimensions:
    - id: food_drive
      name: "食物欲望"
      weight: 0.40
      rules:
        - condition: "approach_latency < 1.0 and approach_speed > 2.0"
          score: 90
          label: "高"
        - condition: "approach_latency < 3.0"
          score: 60
          label: "中"
        - condition: "approach_latency >= 5.0"
          score: 20
          label: "低"
    - id: prey_drive
      name: "猎物欲望"
      weight: 0.40
      rules: [...]
    - id: courage
      name: "胆量"
      weight: 0.20
      rules: [...]
  thresholds:
    pass: 70       # 合格
    borderline: 60 # 基本合格
    fail: 0        # 淘汰
```
