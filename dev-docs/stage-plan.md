## 2. 完整项目方向（2026-08-19 规划）

### 2.1 当前状态

**已完成（Phase 1-3）**：
- YOLO26-pose 24 关键点姿态检测（Box mAP50=96.1%）
- 规则引擎 8 + 16 类行为识别
- ST-GCN+BC 22 类行为识别（合成数据 46.97%）
- 双场景评分引擎（选育 + 测评 + FCI-IGP）
- 多犬追踪（BoxMOT + ReID，MOTA 93.33%）
- 3D 姿态重建（MPJPE 21.74mm）
- YAML 配置化评分卡 + PDF 报告 + 前端可视化
- RBAC 5 角色 + 训练历史对比
- **核心瓶颈**: ST-GCN+BC 在真实数据上仅 46.97%（合成数据），需 ≥85%

**已启动（P0 + Phase 4）**：
- P0 数据解阻：AimCLR + SMQ + TCL + 主动学习（ADR 0012）
- Phase 4 LLM：实验室 Agnes API → 本地 LLM 行为解释器（ADR 0011）
- Phase 4 Mamba：Mamba 基线 85.61%（合成数据），需真实数据验证

### 2.2 P0: 数据解阻（3-4 周，当前）

> 详细子阶段见 `stages/data-unblocking.md`

**目标**：解决数据阻塞，ST-GCN+BC ≥85% 22 行为分类

```
未标注视频 (InterPet4D/AK/APTv2/SyDog-Video)
    │
    ▼  AimCLR 自监督预训练
骨架 embedding
    │
    ▼  SMQ 无监督时序分割
动作 episode 边界
    │
    ▼  TCL 半监督原型聚类
22 行为原型
    │
    ▼  主动学习：不确定性采样
100-200 片段人工标注
    │
    ▼  ST-GCN+BC 微调
22 类 ≥85%
```

**子阶段**：
| 子阶段 | 周期 | 关键交付 | 验证 |
|--------|------|---------|------|
| P0.1 AimCLR 预训练 | 1 周 | 预训练权重 + kNN 评估 | kNN top-1 > 随机基线 ×5 |
| P0.2 SMQ 分割 | 1 周 | 分割模型 + 边界可视化 | 边界 IoU > 0.5 |
| P0.3 TCL + 主动学习 | 1 周 | 22 原型 + 100 采样清单 | 聚类纯度 > 0.6 |
| P0.4 ST-GCN+BC 微调 | 1 周 | 微调模型 ≥85% | 22 类 top-1 ≥85% |
| P0.5 论文初稿 | 并行 | Pattern Recognition 初稿 | 审稿人标准 |

**数据源**：
| 数据源 | 用途 | 状态 |
|--------|------|------|
| InterPet4D 226 seq | AimCLR 预训练 + SMQ 分割 | ✅ 已有 |
| Animal Kingdom 338 犬科 | AimCLR 预训练 + SMQ 分割 | ✅ 已有 |
| APTv2 全量 242K | AimCLR 预训练扩展 | ✅ 已有 |
| SyDog-Video 500 合成视频 | AimCLR 预训练增强 | ⏳ 待下载 |
| samtwl 犬类行为数据集 | 行为识别补充 | ⏳ 待请求 |
| 真实 K9 训练视频 10-15 段 | 主动学习标注素材 | ⚠️ 用户需提供 |

### 2.3 Phase 4.1: 基座系统产品化（P0+4-6 周）

**目标**：将 P0 产出的方法论管线产品化，接入现有推理系统

**关键动作**：
1. AimCLR 骨架编码器 → 正式 ML 模块（`backend/ml/behavior/foundation/`）
2. SMQ 分割 → 行为 episode 检测器（替换当前滑动窗口）
3. TCL 原型 → 在线行为分类（无需硬编码标签）
4. 数据飞轮闭环：自动标注 → 训练 → 部署 → 反馈
5. 22 行为分类在真实数据上稳定运行（≥85%）

**交付**：
- 基座系统管线（物理-语义解耦）
- 小样本数据飞轮（新增 10 标注 → 精度提升 2%+）
- 端到端脚本：`python pipeline.py --video input.mp4 --report output.pdf`

### 2.4 Phase 4.2: LLM 行为解释器（与 4.1 并行，2-3 周）

**目标**：训练结束后，自然语言解释训练行为 → 训导员可理解的训练反馈

**双阶段**：
| 阶段 | 模型 | 数据出境 | 状态 |
|------|------|---------|------|
| 实验室阶段 | Agnes API | 临时豁免（用户确认） | ⏳ 待实现 |
| 实用阶段 | 本地大模型（Llama 3.2 1B 或等价） | 不出本地 | ⏳ 待实现 |

**交付**：
- LLM 行为分析报告（API: `POST /api/llm/explain`）
- 前端对比页面增加 LLM 分析按钮
- 代码环境变量解耦，配置级切换（ADR 0011 v1.1）

### 2.5 Phase 4.3: Mamba 生产替换（与 4.1 并行，4-6 周）

**目标**：Mamba 基线 ≥85% → 替换 ST-GCN+BC 为 Mamba 推理引擎

**当前状态**：
- Mamba 基线：85.61%（合成数据）vs ST-GCN+BC 46.97%
- mamba_ssm WSL 编译通过（RTX 5060 sm_120）
- tasks.py 集成路由（10 种 behavior_deploy_mode）

**待完成**：
1. 真实数据训练（P0 产出标注数据后）
2. Mamba ONNX 导出
3. 生产推理引擎
4. 消融实验：Mamba-only vs Transformer-only vs Hybrid
5. 延迟对比（目标 ≤0.5x）

### 2.6 Phase 5: 产品落地（4-6 周）

**目标**：真实警犬/海关基地部署

**关键动作**：
1. 找 1-2 个警犬训练基地试点
2. 真实工作犬数据采集（上传视频 → 评分 → 反馈）
3. Jetson Orin Nano Super 边缘部署（TRT FP16）
4. 多基地数据隔离（RBAC 已就绪）
5. 训练反馈闭环（训导员 → 系统 → 模型）

**交付**：
- 基地级部署文档
- 多基地看板
- 模型远程更新机制

## 5. 风险与应对

### 5.1 当前阶段风险（P0 数据解阻）

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 用户无法提供真实训练视频 | 60% | 高 | 回退：用 AK 犬科视频 + 标签映射（上限 60-70%），论文聚焦方法论 |
| samtwl 数据集请求被拒 | 30% | 中 | 纯用自监督 + 主动学习 |
| AimCLR 在狗骨架数据上不收敛 | 20% | 中 | 换用 SimCLR / BYOL 等更稳定的自监督方法 |
| SMQ 分割质量差 | 30% | 中 | 改用滑动窗口 + 相似度分割 |
| ST-GCN+BC 在少量标注上 <85% | 40% | 中 | 数据增强 + 迁移学习 + 论文 Method 改为 few-shot 设定 |

### 5.2 中长期风险

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 基地合作谈不下来 | 50% | 高 | 先做纯公开数据 + 学术论文，基地合作作为 Phase 5 启动条件 |
| Jetson 部署性能不达标 | 30% | 中 | 退化为 ONNX Runtime GPU 推理 |
| Mamba 在真实数据上不优于 ST-GCN | 30% | 中 | 保留 ST-GCN+BC 为生产主力，Mamba 作为论文消融对比 |
| LLM 本地模型效果差 | 30% | 中 | 保留模板化报告 + LLM 扩展模式 |
