## 1. 大阶段原则（来自 sliver-vibe-coding）

- 每个大阶段让**至少一个用户角色**完成**一个有意义的产品流程**
- 不允许"仅登录"这种过小阶段
- 不允许包含多个不相关用户角色的过大阶段
- 阶段升级由用户判断（不设硬性精度阈值）
- 每阶段完成后需 `reports/phase-{N}-validation.md` 验证报告

## 4. 各阶段用户角色与产品流程

### Phase 0 — 基础设施
- **用户角色**：无（开发者自验）
- **产品流程**：环境可运行 + 骨架启动 + DB schema 就位
- **不交付**：任何业务功能

### Phase 1 — MVP 端到端闭环
- **用户角色**：训导员
- **产品流程**：上传视频 → 等待推理 → 查看评分报告（PDF）
- **覆盖功能**：F1 视频上传 + F2 姿态检测（YOLO26-pose）+ F3 行为识别（规则+PoseC3D 8 类 P0）+ F4 评分（GA-T 3 维）+ F5 评分报告（PDF）+ F7 犬只档案（基础 CRUD）

### Phase 2 — 数据飞轮 + 16 行为
- **用户角色**：训导员 + 科研人员
- **产品流程**：训导员持续上传视频积累数据 → 科研人员对比模型版本
- **覆盖功能**：F6 训练历史对比 + F8 模型管理 + F3 扩展 16 类 + F4 加 USPCA

### Phase 3 — 专业功能
- **用户角色**：训导员 + 管理层
- **产品流程**：多犬/多摄像头场景的完整评分
- **覆盖功能**：F10 多犬追踪 + F11 3D 重建 + F9 基地统计 + F3 扩展 22 类 + F4 加 FCI-IGP

### Phase 4 — 前沿方法（按需）
- **用户角色**：训导员
- **产品流程**：自然语言训练反馈 + 长视频分析
- **覆盖功能**：F12 LLM 解释器 + F13 长序列 + F14 RL 评分优化

## 6. 跨阶段共享约束

- **本地部署**：Phase 1-3 严格本地化，无云依赖
- **数据隐私**：公安/海关场景，数据不出本地
- **三大标准兼容**：GA-T（Phase 1）/ USPCA（Phase 2）/ FCI-IGP（Phase 3）逐阶段引入
- **22 种行为分类**：P0 基础 8 种（Phase 1）/ P1 训练 8 种（Phase 2）/ P2 高级 6 种（Phase 3）
- **7 维评分**：3 维（Phase 1）→ 5 维（Phase 2）→ 7 维（Phase 3）
