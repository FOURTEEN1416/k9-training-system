## 1. 上下文

### 1.1 Phase 2 启动前置条件已达成

依据 ADR 0005 v1.1 + ADR 0006 v1.1，Phase 2 启动前置条件于 2026-07-28 全部达成：

| 前置条件 | 状态 | 依据 |
|---------|------|------|
| 1.6d 真实序列验证 | ✅ 通过 | InterPet4D 226/226 clips + 9/9 姿态指标变异（`reports/phase-2-prereq-1.6d-validation.md`） |
| 1.2f 真实数据复核 | ✅ 条件通过（数据限制） | 合成 92.9% + kp_world 管线 100%（`reports/phase-2-prereq-1.2f-validation.md` v1.1） |

### 1.2 用户决策

用户确认 **Case A：升级 Phase 2**，真实视频补强作为 Phase 2 首批任务。同时推进 **Case B：1.2f 补强方案调研**（含视频+标签数据集 + YouTube 自标），作为 Phase 2 并行任务。

### 1.3 Phase 2 范围（来自 function-list.md + stage-plan.md）

- **数据飞轮**：用户上传 → 标注 → 微调闭环
- **16 类 P1 行为扩展**：在 P0 8 类基础上增加（追踪/示警坐/示警卧/扑咬/押解/障碍穿越/返回/警戒，依据 RESEARCH_STANDARDS.md §4.1）
- **USPCA 标准映射**：评分卡扩到 5 维（准确度/延迟/保持/搜索效率/注意力）
- **用户权限**：多训导员 + 基地管理员角色
- **基地合作落地**：1-2 个警犬基地试点
- **真实工作犬数据采集 + 标注**
- **训练历史与对比**（F-old-6，Phase 1 延后到 Phase 2）

## 2. 决策

### 2.1 确认升级 Phase 2

**确认 Phase 2 启动**。Phase 1 MVP 验收通过（带条件）+ 1.6d/1.2f 前置条件达成，满足升级要求。

### 2.2 Phase 2 首批任务（并行推进）

| 任务 | 优先级 | Owner | 依赖 |
|------|--------|-------|------|
| **2.0 真实视频补强 1.2f** | P0 | ML 开发 | 含视频+标签数据集（Case B 调研） |
| **2.0b YouTube 玩球视频物体检测** | P0 | ML 开发 | YouTube 视频下载 |
| **2.1 数据飞轮基础设施** | P0 | 后端开发 | DB migration（标注表 + 用户表） |
| **2.2 16 类 P1 行为扩展** | P1 | ML 开发 | 规则引擎扩展 + 标注数据 |
| **2.3 USPCA 评分卡 5 维** | P1 | ML 开发 | 评分卡 YAML 扩展 |
| **2.4 用户权限 + 多租户** | P1 | 后端开发 | RBAC + 基地管理员角色 |
| **2.5 训练历史与对比** | P2 | 前端 + 后端 | 历史评分查询 + 对比可视化 |

### 2.3 Phase 2 出口条件

- 16 类 P1 行为规则引擎准确率 ≥ 85%（真实数据）
- USPCA 5 维评分卡验证通过
- 数据飞轮闭环（标注 → 微调 → 部署）
- 用户权限多角色验证
- 1.2f 真实视频准确率 ≥ 80%（补强后）
- 端到端延迟 ≤ 1 min/min 视频（维持）

### 2.4 Phase 2 时间约束

按 `stage-plan.md` §4：+4-6 周单人全职。子阶段分解见 `stages/phase-2.md`。

## 3. 风险与缓解

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 1.2f 补强数据集获取困难 | 40% | 高 | Case B 调研 Animal Kingdom + YouTube 自标并行 |
| 16 类行为标注成本高 | 50% | 中 | 数据飞轮 + 主动学习 + 半自动标注 |
| USPCA 标准映射不全 | 30% | 中 | 仅映射覆盖的 5 维，其余延后 |
| 基地合作落地周期长 | 60% | 中 | 先用公开数据，基地数据作为补强 |
| 数据飞轮微调闭环复杂 | 40% | 中 | 分阶段：标注 → 训练 → 部署，每阶段独立验收 |
