# ADR 0012：基座系统方向决策

## 状态: ✅ 已确认 (2026-08-19)

## 背景

Phase 1-3 开发完成后，系统数据产生阻塞——真实标注数据缺失导致 ST-GCN+BC（合成 46.97%）和 Mamba（合成 85.61%）无法在真实数据上验证/升级。用户决策暂停系统开发，全面解决数据问题。

同时，用户提出构建"适应动态业务逻辑的视觉基座系统"构想：**当评分标准和动作语义变化后，系统依然能低成本完成动作识别和模型训练**。经系统性调研（7 方向 37 个仓库，GitHub-First，零 WebSearch），确认该构想学术上成立、技术上可行。

## 决策

### 决策 1：基座方向确认为项目新方向（取代原"直接人工标注"路径）

项目从"系统开发交付"转向"方法论基座构建"。核心定位：

> 构建一套物理-语义解耦的视觉基座方法论：物理运动表征层（标准无关）+ 动态语义注入层（标准变化自适应）+ 小样本自监督数据飞轮（低资源快速适配）。

### 决策 2：P0 实现路径

采用 **AimCLR（AAAI 2022，MIT 许可）自监督预训练 + SMQ（ICCV 2025）骨架无监督时序分割 + TCL（CVPR 2021）半监督自训练** 技术栈，结合主动学习，打通数据飞轮。

### 决策 3：标注量

主动学习将人工标注量从 682 片段压缩到 **100-200 片段**，分 2-3 轮迭代。

### 决策 4：论文目标

主攻 **Pattern Recognition（IF≈8.0）/ IJCV**，方法论抽象化为"面向动态评价标准的物理-语义解耦低资源动物行为识别框架"。

### 决策 5：keypoint-MoSeq

**存档废弃**。原因：InterPet4D 数据以卧姿为主，43 syllables 中 32 已映射但几乎全是 down，类覆盖不足，P1/P2 行为无法覆盖。

### 决策 6：创建 ADR 记录方向决策

本 ADR 即为此决策记录。

### 学术方向对齐

本 ADR 与已确认的学术主方向（可解释评分卡 + 端到端工作犬评估系统，2026-08-19 用户确认）**协同增强**：
- 可解释评分卡 = L4 动态语义层的产品化表现
- 端到端系统 = L1-L4 全栈
- 新增：L3 数据飞轮成为论文核心方法论创新，提升论文档次从"系统论文"到"方法论文"

## 不可逆操作清单

- ⏳ 数据飞轮管线实施后，原始标注策略（全量 682 人工标注）不再执行
- ⏳ keypoint-MoSeq 路径废弃，相关训练产物仅存档不再维护

## 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 骨架无监督分割质量不达预期 | 40% | 中 | AimCLR 预训练 + TCL 半监督 + 主动学习多轮纠偏 |
| 时序域伪标签确认偏差 | 50% | 高 | 不确定性估计 + 主动学习人工复核 top 不确定样本 |
| 682 片段场景单一 | 70% | 中 | 扩充无标注池：APTv2 犬类 + InterPet4D 片段 |
| 论文被质疑"只是半监督迁移" | 50% | 中 | 强调物理-语义解耦 + 动态标准自适应 + 时序域迁移的三重贡献 |
