# ADR 0013 — 研究仓库拆分：P0/论文主线移交 psd-framework

- 状态: ✅ 已确认
- 日期: 2026-08-23
- 决策人: 用户
- 下游对应: `D:\Desktop\psd-framework\dev-docs\decisions\0001-repo-split.md`

## 背景

2026-07-26 至 08-20 项目经历 5 次方向演进，v1.29 定调"学术研究为主"。用户对方向的最终口径（2026-08-23）：

- **④ K9 产品系统 + ⑤ Phase 4 升级（LLM 解释器 / Mamba 产品化）= 产品升级线**
- **① 基座愿景 + ② PR/IJCV 论文 + ③ P0 数据解阻 = 研究线**，服务于"发论文实现终极野心（适应动态业务逻辑的视觉基座系统）"

两条线交付节奏（论文快迭代 vs 产品稳定）、代码风格、开源要求完全不同，同仓互相拖累。

## 决策

AI 曾推荐"先内后外两步走"（研究代码先留本仓 `research/` 目录，投稿前再拆）；用户权衡后选择**立即独立建仓**，理由：完整实现最终野心需要干净载体。

| 归属 | 内容 |
|------|------|
| **psd-framework（新仓库）** | ① 基座愿景 ② 论文 ③ P0 数据解阻（P0.1-P0.6） |
| **本仓库** | ④ K9 产品系统（Phase 1-3 已关闭，冻结为验证平台）⑤ Phase 4 产品升级 |

Mamba 双角色：产品替换在本仓库推进；85.61% 合成基线允许被新仓库移植作论文骨干候选。

## 执行记录（2026-08-23）

1. 新仓库建立：git init + truth 链（brief v1.0 / stage-plan v1.0 / ADR 0001 / assets-map / 精简宪法 AGENTS.md v1.0）+ 5 份调研文档复制 + `psd/` 包骨架
2. 本仓库同步：stage-plan v1.12 + `stages/data-unblocking.md` 冻结移交标注 + dev-docs/README + HANDOVER v1.5 + 本 ADR
3. 代码资产**未搬移**——移植时以新仓库验证为准，映射清单见 `psd-framework/docs/assets-map.md`

## 后果

- 本仓库定位收窄为**产品验证平台**；研究产出回流产品通过显式移植发生
- 跨仓只允许文档指针，禁止跨仓 import
- 论文开源时直接以 psd-framework 为发布载体，无需二次剥离
