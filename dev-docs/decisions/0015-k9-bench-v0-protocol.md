# ADR 0015：K9-Bench-v0 真实识别评测协议（预注册）

## 状态: 📋 预注册草案（2026-10-19）——数据范围经用户确认后生效并冻结

> 依据: `dev-docs/production-readiness-gap-plan.md` P0-3（先于一切刷分，防测试集泄漏）
> 性质: **预注册协议**。生效后切分/指标/门槛冻结，任何修改须走新版本号（v0.1→v0.2）并书面说明理由。
> 上位验收: gap-plan §1 生产可用 A3「识别可信」的唯一评测依据；合成层/论文层指标一律不得充数。

---

## 1. 目的

定义在**真实工作犬视频**上评测行为识别精度的统一协议，使「识别过线 → 部署模式切换」
（rule_only → vote → primary_*）有书面依据，杜绝：
- 用合成数据准确率冒充生产精度；
- 测试集片段泄漏进训练/调参（按犬、按场次双隔离）；
- 事后挑选指标/切分（预注册冻结）。

## 2. 数据源与范围

| 项 | 定义 | 状态 |
|----|------|------|
| 视频来源 | 真实工作犬训练/考核视频（基地自有 / 合作单位 / 自行拍摄） | ⏳ **待用户裁决**（gap-plan §12-1） |
| 保密级别 | 是否允许标注外包 / 是否必须全离线 | ⏳ **待用户裁决**（§12-2） |
| 首发科目 | 建议 P0 八类优先或 3–5 个核心科目 | ⏳ **待用户裁决**（§12-3） |
| 规模目标 | 每优先类 ≥50–100 有效 episode，总 300–1000+ | 目标值（P1-1） |
| 部署目标机 | 本机工作站 / 基地 GPU 机 / 后续 Jetson | ⏳ **待用户裁决**（§12-4） |

**硬性排除**：公开数据集（Animal Kingdom / APTv2 / InterPet4D）不得进入 K9-Bench-v0——
它们的域与训练场景不符（gap-plan §0 G1 / §7 移植纪律：论文数字不能当产品指标）。

## 3. 切分协议（防泄漏）

1. **按犬隔离**：同一犬只的片段不得同时出现在训练集与测试集。
2. **按场次隔离**：同一场训练/考核的不同机位/片段归同一 fold。
3. 切分表落盘 `data/k9_bench/v0/splits.json`，含 video_id / dog_id / session_id / fold 四字段。
4. **禁止事项**：测试集 episode 禁止进入任何训练/调参/早停决策；自动标注模型的伪标签
   仅允许在训练 fold 内生成。

## 4. 标签 Schema

- **行为类别**：与系统 22 类枚举（`backend/app/models/behavior.py` BehaviorClass）+ P0/P1/P2 分层一致；
  标签值使用枚举名（SIT/DOWN/...），中文对照以 YAML 评分卡为准。
- **标注单元**：episode（起止帧 + 类别 + 标注人 + 置信备注）。
- **标注规范**：起止帧以行为姿态完成为界（±0.5s 容差）；模糊片段标 `UNCERTAIN` 不计入指标分母。
- **一致性抽检**：双标 kappa ≥ 0.75 或人工抽检一致率 ≥ 90%，未达标批次整批重标。

## 5. 指标

| 指标 | 口径 |
|------|------|
| top-1 accuracy | episode 级主类正确率（宏平均权重相同） |
| macro-F1 | 22 类宏平均（含 per-class P/R/F1 全表） |
| 分层指标 | P0/P1/P2 分层 + IGP A/B/C 分层准确率 |
| 边界 F1 | 边界偏移容忍窗（0.5s/1.0s 两档） |

## 6. 部署门槛（与 `backend/ml/behavior/router.py` 注释一致）

| 测试集成绩 | 允许模式 | 说明 |
|-----------|---------|------|
| < 70% | `rule_only`（默认） | 规则引擎 + 人工复核，报告标注「自动识别·建议人工复核」 |
| ≥ 70% | `vote` | 双轨投票，人工抽检报告 |
| ≥ 85% | `primary_stgcn` / `primary_mamba` | 深度模型主路径，规则引擎降级备 |

未达标类别保持 rule/人工，不按全局成绩一把切换。

## 7. 报告格式

每次评测归档 `reports/k9-bench-v0-<日期>.md|json`，必备字段：
协议版本、数据快照版本（splits.json 哈希）、模型版本（权重文件名+hash 前 8 位）、
识别模式、top-1/macro-F1/per-class 表/混淆矩阵/边界 F1、未达标类清单、
结论与模式切换建议。P0-5 报告溯源字段（识别模式/模型版本/复核标记）为必填。

## 8. 反验收条款（禁止）

- 用合成层/论文层数字宣称生产达标；
- 测试集进训练或早停；
- 隐藏识别模式，让报告看起来像深度模型结果；
- 预注册后修改指标定义或切分方式（须新版本号 + 理由书面化）。

## 9. 生效条件

1. 用户裁决 §2 五项待定项（视频来源/保密级别/首发科目/规模/目标机）；
2. 首批真实视频入库并完成 splits.json 切分表；
3. 双标一致性抽检通过（§4）。

三条齐备后本文档状态转 ✅ 生效并冻结。
