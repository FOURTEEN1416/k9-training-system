# ADR 0011：Phase 4 LLM行为解释器

## 状态: ✅ 已实施 (2026-08-02)，v1.1 修订 (2026-08-19)

> **v1.1 决策修订（2026-08-19，用户确认）**：LLM 后端采用**双阶段策略**——
> - **实验室阶段（当前）**：使用 **Agnes 2.5 Flash 外部 API**（`apihub.agnes-ai.com`，行为概率/评分上传云端）。用户明确接受实验室阶段数据出本地，用于快速验证解释器质量与提示词工程。
> - **实用阶段（后期）**：切换为**本地大模型**（原选项 A Llama 3.2 1B 或等价本地模型），恢复"数据不出本地"硬约束，满足公安/海关场景数据隐私要求。
> - 实现代码已按环境变量解耦（`LLM_API_KEY` / `LLM_API_BASE` / `LLM_MODEL`），切换仅需改配置，无需改代码。已实现模板降级（模型不可用时输出结构化模板报告）。
> - **注意**：本项目 PRD 硬约束为"数据不出本地"（公安/海关场景），实验室阶段的云端调用是**用户确认的临时豁免**，实用阶段前必须回退本地模型（列入 HANDOVER P1 待办跟踪）。

## 背景
Phase 3 已完成 ST-GCN+BC 行为识别模块，提供 22 类行为分类结果。然而，仅有行为概率分布对训导员缺乏解释意义，训导员需要了解 “为什么是 这一行为” 以及 “如何改进”。

## 决策选项

### 选项 A：本地部署 LLM
- **模型**: Llama 3.2 1B (8bit量化)
- **优点**: 
  - 无持续成本，一次部署永久使用
  - 数据不出本地，符合项目本地化原则
  - CPU推理 ≈ 2s/次，满足交互需求
- **缺点**: 
  - 需要本地硬件支持 (已在 RTX 5060 验证)
  - 模型维护责任自负
- **适用性**: 本项目首选，符合“本地化、无云依赖”原则

### 选项 B：OpenAI API
- **模型**: gpt-4o-mini
- **优点**: 
  - 质量最高，效果最好
  - 无需自行部署和维护
- **缺点**: 
  - 持续成本 (约 $0.0005/次)
  - 数据将上传至云端 (违反项目数据隐私原则)
  - 依赖网络环境
- **适用性**: 备选方案，当本地部署不可行时

### 选项 C：规则解释器
- **实现**: 基于已有的规则引擎和业务逻辑
- **优点**: 
  - 开发成本最低
  - 数据完全本地
  - 延迟最低
- **缺点**: 
  - 解释能力有限，无法处理复杂场景
  - 随业务增长可扩展性差
- **适用性**: 作为 Phase 3 的延续，非 Phase 4 重点

## 决策建议

**推荐（原决策）**: 选项 A (本地部署 Llama 3.2 1B)
- 理由: 符合项目“本地化、无云依赖、数据隐私”三大核心原则
- 成本: 一次性硬件成本 (已在 RTX 5060 上验证)，零持续成本
- 延迟: ≈ 2s/次，满足训导员交互需求

**备选（原决策）**: 选项 B (OpenAI API)
- 场景: 本地部署不可行时的备选
- 成本: 预算 $500/年，用于度量后决定是否转为选项 A

**实际实施（v1.1 修订，2026-08-19）**: 选项 B 变体 — **Agnes 2.5 Flash 外部 API（实验室阶段）**
- 用户决策: 实验室阶段维持 Agnes API（接受数据出本地，用于快速验证），后期实用阶段切换本地大模型
- 与选项 B (OpenAI) 的区别: Agnes 为免费 API（零成本），已通过 `LLM_API_BASE` 环境变量解耦，可无缝切换任意 OpenAI 兼容端点或本地推理服务
- 数据隐私: 实验室阶段豁免（用户确认），实用阶段强制回退本地（列入 HANDOVER P1 跟踪）

## 风险与缓解

| 风险 | 概率 | 缓解措施 |
|------|------|----------|
| 模型加载缓慢 | 40% | 使用 4bit 量化而非 8bit，或预热模型 |
| 提示词工程不佳 | 60% | 多轮迭代，邀请训导员参与提示词设计 |
| 输出质量不达标 | 70% | 设立人工评审机制，迭代优化提示词 |
| 硬件不支持 AVX-512 | 30% | 回退至纯 CPU 模式 (仍在可接受延迟范围) |
| **实验室云端 API 依赖（v1.1 新增）** | 100% 已知 | 实用阶段切换本地模型；代码已环境变量解耦，配置级切换；模板降级兜底 |
