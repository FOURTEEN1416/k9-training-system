### 2.3.2 Label Studio 部署详情（v1.3 新增）

**版本与配置**:
- Label Studio 1.23.0（pip 安装于项目 .venv）
- 数据目录: `data/youtube_self_label/ls_data`（相对路径，避免沙盒限制）
- 服务地址: `http://127.0.0.1:8080`
- 账号: `admin@k9.local` / 密码: `k9admin2026`
- 项目 ID: 1
- 项目标题: "K9 行为标注 — YouTube 自标（Phase 2.0a 路径 B）"
- 标注配置: `data/youtube_self_label/label_studio/label_config.xml`（视频检测框 + 行为类别）

**认证方式**: Django session cookie（CSRF + form POST）
- Label Studio 1.23 默认禁用 legacy DRF token（`TokenAuthenticationPhaseout`）
- JWT 端点 `/api/token/` 仅管理已认证用户的令牌，不签发登录令牌
- 最简方案: `/user/login/` 表单 POST → session cookie + `X-CSRFToken` header

**部署脚本**: `scripts/_setup_ls_project.py`（幂等，可重复执行）
1. GET `/user/login/` 获取 CSRF cookie
2. POST `/user/login/` 表单登录（email/password/csrfmiddlewaretoken）
3. GET `/api/projects/` 检查/创建项目
4. GET `/api/projects/{id}/tasks/` 检查任务数（决定是否需导入 JSON）
5. POST `/api/projects/{id}/import` (JSON) 导入预标注任务（仅项目为空时）
6. POST `/api/projects/{id}/import` (multipart) 上传视频 → 创建 FileUpload 记录
7. GET `/api/projects/{id}/tasks/` 删除空任务（无 predictions 的上传残留）
8. GET `/api/projects/{id}/file-uploads?all=true` → PATCH `/api/tasks/{id}/` 修复视频 URL
9. HEAD `/data/upload/<...>` 验证视频可访问

**关键技术细节**: Label Studio 上传文件时自动添加 8 字符 hex UUID 前缀并存储于 `<media>/upload/<project_id>/<uuid8>-<original>` 路径下。预标注 JSON 中的 `/data/upload/<filename>` URL 必须通过 FileUpload API 查询实际路径后 PATCH 更新，否则视频在标注界面无法加载。

- 5 个预标注任务全部就绪（task id=1-5，每个含 1 个 prediction）
- 5 个视频 URL 全部返回 200（session 鉴权可访问）
