# 数据解阻（P0）阶段计划

> 状态: ⏸️ 已移交冻结（2026-08-23，ADR 0013）——现行计划由 `D:\Desktop\psd-framework\dev-docs\stage-plan.md` 接管推进；本文件保留为立项期规划记录
> 依据: ADR 0012（基座系统方向）+ 系统性调研结论（7 方向 37 仓库）
> 技术栈: SMQ（ICCV 2025）+ AimCLR（AAAI 2022）+ TCL（CVPR 2021）+ **姚青 JIA 迁移（核心创新）**
> 论文定位: Pattern Recognition / IJCV

## 1. 阶段目标

**一句话**：完成方法论管线与论文实验，分别评估合成、公开真实和真实 K9 目标域表现；真实 K9 视频不是启动硬依赖。

**核心创新候选**：在当前文献检索范围内，拟将图像域小样本伪标签方法（姚青 JIA：VFM 骨干 + 锚点学习 + 聚类 + 伪标签）迁移到**时序骨架域**；“首次”主张待论文阶段进一步核验。

**交付物**：
1. ⏳ **论文级方法论管线**：规则种子 → AimCLR → SMQ → TCL → 姚青 JIA → 主动学习 → ST-GCN+BC
2. ⏳ **训练模型**：按合成、公开真实、真实 K9 三层指标口径评估 22 类行为分类
3. ⏳ **论文初稿**（Pattern Recognition / IJCV）

## 2. 技术路线

```
规则引擎粗标（种子）—— 物理层先验
    │
    ▼
[AimCLR 自监督预训练]  ← AAAI 2022，骨架对比学习，NTU 60 → 79.18%
    │
    ▼
[SMQ 无监督时序分割]  ← ICCV 2025，运动词向量量化，输入 (T,24,3) 直接兼容
    │
    ▼
[TCL 半监督自训练]  ← CVPR 2021，时序对比学习，10% 标注 → 82.7%
    │
    ▼
[姚青 JIA 方法迁移 🔥—— 核心创新]
  ├── VFM 骨干（骨架域适配）
  ├── 锚点学习（时序动作锚点）
  ├── 聚类（行为原型聚类）
  └── 伪标签迭代
    │
    ▼
[主动学习：不确定性采样]  ← 100-200 片段人工标注
    │
    ▼
[ST-GCN+BC 微调]  → 22 类 ≥85%
```

## 4. 子阶段计划

### P0.1: AimCLR 管线搭建 + 预训练（1 周）

**目标**：AimCLR 训练管线跑通，在 InterPet4D + AK 上完成预训练，kNN top-1 评估 > 随机基线 4.5% 数倍

**动作**：
1. 搭建 AimCLR 骨架编码器（ST-GCN 主干或 Transformer 骨干）
2. 数据加载器：InterPet4D smal_npy 24 关键点 × 3D 序列
3. 预训练：50-100 epoch，对比学习
4. 评估：kNN top-1 准确率，对比随机初始化 + 规则引擎基线
5. 输出：预训练权重 + 评估报告

**验证**：`python scripts/eval_aimclr.py --pretrained runs/aimclr/best.pt --knn --top-1`

### P0.2: SMQ 时序分割集成（1 周）

**目标**：SMQ 在 AK 犬科视频上产出合理的动作 episode 边界

**动作**：
1. SMQ 网络搭建（时序分割 Transformer）
2. 将 AK 视频级语义标签转化为 episode 级弱监督信号
3. InterPet4D 5 类标签作为辅助信号
4. 评估：分割边界与人工标注的一致性（IoU）
5. 输出：SMQ 分割模型 + 分割结果可视化

**验证**：`python scripts/eval_smq_segmentation.py --model runs/smq/best.pt --iou`

### P0.3: 姚青 JIA 方法迁移（核心创新）（1 周）

**目标**：将图像域 VFM+锚点+聚类+伪标签方法迁移到时序骨架域，产出 22 行为原型

**动作**：
1. VFM 骨干适配：将图像域 VFM 骨干替换为时序骨架编码器（ST-GCN 或 Transformer）
2. 锚点学习：时序动作锚点，从 AimCLR embedding 空间学习
3. 聚类：行为原型聚类为 22 类
4. 伪标签迭代：用聚类结果生成伪标签，自训练迭代
5. 输出：JIA 迁移方法 + 行为原型 + 伪标签

**验证**：`python scripts/eval_jia_migration.py --prototypes --purity`

### P0.4: TCL 半监督训练 + 主动学习（1 周）

**目标**：TCL 时序对比学习增强伪标签质量 + 主动学习采样

**动作**：
1. TCL 搭建（时序对比学习）
2. 用 AimCLR embedding + SMQ 分割 + JIA 伪标签作为输入
3. 10% 标注 → 接近全监督的伪标签增强
4. 不确定性采样：选 100-200 个最不确定的片段
5. 输出：增强伪标签 + 主动学习样本清单

**验证**：`python scripts/eval_tcl_prototypes.py --model runs/tcl/best.pt --clusters`

### P0.5: ST-GCN+BC 微调（1 周）

**目标**：在主动学习标注样本上微调 ST-GCN+BC，并按三层数据口径报告结果；≥85% 是公开真实/目标域参考目标，不是合成数据结论。

**动作**：
1. 优先使用真实训练视频；不可获得时使用公开数据池，标注 100-200 个主动学习片段
2. 转换为 pyskl pickle 格式
3. 微调 ST-GCN+BC（从 AimCLR 预训练权重初始化）
4. 评估：22 类准确率、边界 F1、P0/P1/P2 分层
5. 输出：微调模型 + 评估报告

**验证**：`python scripts/eval_stgcn_bc.py --model runs/stgcn_bc_real/best.pt --real-data`

### P0.6: 论文初稿（并行）

**目标**：Pattern Recognition / IJCV 论文初稿

**Title**：A Physics-Semantics Decoupled Framework for Low-Resource Animal Behavior Recognition under Evolving Evaluation Criteria

**素材**：
- AimCLR 预训练效果（对比随机基线，NTU 60 复现 79.18%）
- SMQ 分割效果（对比 ground truth，运动词量化）
- **姚青 JIA 迁移（核心创新）**：图像域→时序骨架域，消融实验
- TCL 半监督增强（10% 标注 → 接近全监督）
- 主动学习效率（100 标注 vs 500 标注 vs 全量）
- 端到端效果（22 类 ≥85%）
- 物理-语义解耦架构（评估标准变化验证）
- 对比 Mamba baseline（85.61% 合成数据 vs ST-GCN 46.97%）

## 8. 风险

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 用户无法提供真实训练视频 | 60% | 高 | 回退：用 AK 犬科视频 + 标签映射（上限 60-70%），论文聚焦方法论迁移本身 |
| 姚青 JIA 方法迁移到骨架域不收敛 | 30% | 高 | 简化：VFM→简单 MLP，锚点→KMeans，纯实验方法论仍成立 |
| AimCLR 在狗骨架数据上不收敛 | 20% | 中 | 换用 SimCLR / BYOL 等更稳定的自监督方法 |
| SMQ 分割质量差 | 30% | 中 | 改用滑动窗口 + 相似度分割 |
| ST-GCN+BC 在少量标注上 <85% | 40% | 中 | 论文 Method 改为 few-shot 设定，85% 降为理想目标 |
| 论文创新性被 reviewer 质疑 | 20% | 中 | 强化消融实验 + 物理-语义解耦作为第二创新点 |
