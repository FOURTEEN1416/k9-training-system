# 数据解阻（P0）阶段计划

> 状态: 🔄 立项中（2026-08-19）
> 依据: ADR 0012（基座系统方向）+ ADR 0008 v1.7（YouTube 废弃）
> 数据来源: 2026-08-19 全量数据源调研（GitHub-First 7 方向 37 仓库 + 12 新数据集）

## 1. 阶段目标

**一句话**：解决数据阻塞，使 ST-GCN+BC 在真实数据上达到 ≥85% 22 行为分类准确率。

**交付物**：
1. ✅ 方法论管线（AimCLR + SMQ + TCL + 主动学习，端到端可复现）
2. ✅ 训练模型（≥85% 22 类行为分类，基于真实标注数据）
3. ✅ 学术论文初稿（Pattern Recognition / IJCV）

## 2. 技术路线

```
未标注视频 (InterPet4D/AK/APTv2)
    │
    ▼
[AimCLR 自监督预训练]  ← 无需标注，学习骨架表征
    │
    ▼
[SMQ 无监督时序分割]  ← 动作 episode 边界检测
    │
    ▼
[TCL 半监督原型聚类]  ← 行为原型 → 伪标签
    │
    ▼
[主动学习：不确定性采样]  ← 100-200 片段人工标注（用户提供）
    │
    ▼
[ST-GCN+BC 微调]  → 22 类 ≥85%
```

## 4. 子阶段计划

### P0.1: AimCLR 管线搭建 + 预训练（1 周）

**目标**：AimCLR 训练管线跑通，在 InterPet4D + AK 上完成预训练，kNN top-1 评估 > 随机基线 4.5% 数倍

**动作**：
1. 搭建 AimCLR 骨架编码器（ST-GCN 主干或 Transformer 骨干）
2. 数据加载器：InterPet4D smal_npy 24 关键点 × 3D 序列
3. 预训练：50-100 epoch，对比学习
4. 评估：kNN top-1 准确率，对比随机初始化 + 规则引擎基线
5. 输出：预训练权重 + 评估报告

**验证**：`python scripts/eval_aimclr.py --pretrained runs/aimclr/best.pt --knn --top-1`

### P0.2: SMQ 时序分割集成（1 周）

**目标**：SMQ 在 AK 犬科视频上产出合理的动作 episode 边界

**动作**：
1. SMQ 网络搭建（时序分割 Transformer）
2. 将 AK 视频级语义标签转化为 episode 级弱监督信号
3. InterPet4D 5 类标签作为辅助信号
4. 评估：分割边界与人工标注的一致性（IoU）
5. 输出：SMQ 分割模型 + 分割结果可视化

**验证**：`python scripts/eval_smq_segmentation.py --model runs/smq/best.pt --iou`

### P0.3: TCL 半监督训练 + 主动学习（1 周）

**目标**：TCL 原型聚类产出有意义的 22 行为原型 + 主动学习样本

**动作**：
1. TCL 搭建（原型对比学习）
2. 用 AimCLR embedding + SMQ 分割作为输入
3. 聚类为 22 个行为原型
4. 不确定性采样：选 100-200 个最不确定的片段
5. 输出：聚类结果 + 主动学习样本清单

**验证**：`python scripts/eval_tcl_prototypes.py --model runs/tcl/best.pt --clusters`

### P0.4: ST-GCN+BC 微调 + 真实标注（1 周）

**目标**：在 100-200 手动标注样本上微调 ST-GCN+BC 达到 ≥85%

**动作**：
1. 用户提供 10-15 段真实训练视频 + 标注 100-200 片段
2. 转换为 pyskl pickle 格式
3. 微调 ST-GCN+BC（从 AimCLR 预训练权重初始化）
4. 评估：22 类准确率、边界 F1、P0/P1/P2 分层
5. 输出：微调模型 + 评估报告

**验证**：`python scripts/eval_stgcn_bc.py --model runs/stgcn_bc_real/best.pt --real-data`

### P0.5: 学术论文初稿（并行）

**目标**：Pattern Recognition / IJCV 论文初稿

**素材**：
- AimCLR 预训练效果（对比随机基线）
- SMQ 分割效果（对比 ground truth）
- TCL 原型聚类（可视化）
- 主动学习效率（少样本 vs 全量）
- 端到端效果（22 类 ≥85%）
- 对比 Mamba baseline（46.97% 合成数据）

## 8. 风险

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 用户无法提供真实训练视频 | 60% | 高 | 回退：用 AK 犬科视频 + 标签映射（上限 60-70%），论文聚焦方法论 |
| samtwl 数据集请求被拒 | 30% | 中 | 纯用自监督 + 主动学习 |
| AimCLR 在狗骨架数据上不收敛 | 20% | 中 | 换用 SimCLR / BYOL 等更稳定的自监督方法 |
| SMQ 分割质量差 | 30% | 中 | 改用更简单的滑动窗口 + 相似度分割 |
| ST-GCN+BC 在少量标注上 <85% | 40% | 中 | 数据增强 / 迁移学习 / 本文 Method 部分改为 few-shot |
