## 功能详单

### F1: 视频上传与管理

- **用户**：训导员
- **输入**：视频文件（mp4/avi/mov）或 RTSP 流地址
- **输出**：视频元数据存储、异步推理任务
- **权限**：训导员上传自己的视频
- **正常路径**：上传 → 元数据入库 → 触发异步推理 → 状态更新
- **异常**：格式不支持、文件过大、网络中断
- **边界**：Phase 1 仅支持文件上传，RTSP 在 Phase 3

### F2: 姿态检测（YOLO26-pose）

- **用户**：系统自动
- **输入**：视频帧序列
- **输出**：24 关键点坐标序列（每帧）
- **权限**：内部服务
- **正常路径**：视频解码 → 逐帧推理 → 关键点序列化 → 入库
- **异常**：犬只遮挡、画面模糊、多犬干扰
- **边界**：Phase 1 单犬，Phase 3 多犬追踪

### F3: 行为识别（规则 + PoseC3D + ST-GCN+BC）

- **用户**：系统自动
- **输入**：关键点序列
- **输出**：行为类别 + 时间区间 + 置信度
- **权限**：内部服务
- **正常路径**：关键点序列 → 规则引擎（基础动作）→ PoseC3D（P0）→ ST-GCN+BC（P1-P2）
- **异常**：关键点缺失、行为未知、置信度过低
- **边界**：Phase 1 仅规则+PoseC3D 8 类，Phase 2 扩展 16 类，Phase 3 ST-GCN+BC 22 类

### F4: 评分引擎

- **用户**：系统自动
- **输入**：行为识别结果 + 标准映射
- **输出**：7 维评分（动作准确度/响应延迟/保持时长/搜索效率/注意力/胆量欲望/步态质量）
- **权限**：内部服务
- **正常路径**：行为序列 → 标准映射 → 维度计算 → 加权汇总
- **异常**：标准未覆盖、数据不足
- **边界**：Phase 1 GA-T 3 维，Phase 2 加 USPCA，Phase 3 加 FCI-IGP

### F5: 评分报告生成

- **用户**：训导员
- **输入**：评分结果 + 视频元数据
- **输出**：PDF 报告 + 可视化标注视频
- **权限**：训导员查看自己的报告
- **正常路径**：评分结果 → 报告模板渲染 → PDF 导出 + 标注视频生成
- **异常**：模板渲染失败、视频处理失败
- **边界**：Phase 1 PDF，Phase 2 加 CSV，Phase 3 加可视化标注

### F6: 训练历史与对比

- **用户**：训导员
- **输入**：犬只 ID + 时间范围
- **输出**：历史评分趋势、对比图表
- **权限**：训导员查看自己犬只
- **正常路径**：查询历史 → 趋势分析 → 图表渲染
- **异常**：无历史数据
- **边界**：Phase 2

### F7: 犬只档案管理

- **用户**：训导员、管理层
- **输入**：犬只信息（品种、年龄、训练阶段）
- **输出**：犬只档案 CRUD
- **权限**：训导员管理自己犬只，管理层查看全部
- **正常路径**：CRUD 操作
- **异常**：重复 ID、必填缺失
- **边界**：Phase 1 基础 CRUD

### F8: 模型管理

- **用户**：系统管理员
- **输入**：模型权重、配置
- **输出**：模型版本管理、A/B 对比
- **权限**：仅管理员
- **正常路径**：上传模型 → 版本记录 → 切换/对比
- **异常**：权重损坏、兼容性问题
- **边界**：Phase 2

### F9: 基地统计

- **用户**：管理层
- **输入**：时间范围、维度
- **输出**：基地级统计数据、排行
- **权限**：管理层
- **正常路径**：聚合查询 → 图表渲染
- **异常**：无数据
- **边界**：Phase 3

### F10: 多犬追踪（Phase 3）

- **用户**：系统自动
- **输入**：视频流
- **输出**：多犬 ID 跟踪 + 各自关键点
- **权限**：内部服务
- **正常路径**：检测 → 跟踪 → 关联 → 分别姿态检测
- **异常**：犬只遮挡、ID 切换
- **边界**：Phase 3

### F11: 3D 姿态重建（Phase 3）

- **用户**：系统自动
- **输入**：多摄像头同步视频
- **输出**：3D 关键点
- **权限**：内部服务
- **正常路径**：多视图同步 → 3D 三角化 → 序列化
- **异常**：摄像头未同步、遮挡
- **边界**：Phase 3

### F12: LLM 行为解释器（Phase 4，按需）

- **用户**：训导员
- **输入**：行为识别结果 + 评分
- **输出**：自然语言训练反馈报告
- **权限**：训导员
- **正常路径**：结构化数据 → LLM 提示 → 自然语言报告
- **异常**：LLM 不可用、输出异常
- **边界**：Phase 4

### F13: 长序列行为分析（Phase 4，按需）

- **用户**：系统自动
- **输入**：>30 秒长视频
- **输出**：长序列行为分段
- **权限**：内部服务
- **正常路径**：长视频 → Transformer/Mamba → 行为分段
- **异常**：内存不足、分段错误
- **边界**：Phase 4

### F14: RL 评分优化（Phase 4，按需）

- **用户**：系统自动
- **输入**：训导员历史评分
- **输出**：个性化评分模型
- **权限**：内部服务
- **正常路径**：训导员评分 → RL 训练 → 个性化评分
- **异常**：数据不足、训练不收敛
- **边界**：Phase 4

## 大阶段计划

> 详细 stage-plan 见 `stage-plan.md`（待创建）

| 阶段 | 交付流程 | 验收标准 |
|------|---------|---------|
| Phase 0 | 基础设施 + 骨架 | 环境可运行、DB schema 就位、前后端骨架启动 |
| Phase 1 | MVP 端到端闭环 | 1 段视频 → 评分 PDF |
| Phase 2 | 数据飞轮 + 16 行为 | 工作犬数据微调 + USPCA 映射 |
| Phase 3 | 专业功能 | ST-GCN+BC + 多犬 + 3D + FCI-IGP |
| Phase 4 | 前沿方法（按需） | LLM / Transformer-Mamba / RL |

**大阶段原则**（来自 sliver-vibe-coding）：
- 每个大阶段让至少一个用户角色完成一个有意义的产品流程
- 不允许"仅登录"这种过小阶段
- 不允许包含多个不相关用户角色的过大阶段
