## 0. 使用规则（先读）

1. **每个勾必须附当次证据**：证据 = 命令 + 实际输出，或报告文件路径 + 其中的字段/行号。
   没有证据的项一律保持未勾选，并在备注写「未验证（本线不声明）」。
2. **本检查单不是“跑过命令”的清单**，而是“结果达标”的清单。命令存在 ≠ 能力就绪。
3. **未验证 ≠ 通过**：`.env`、模型权重、数据切分、回滚、密钥轮换等任何一项无法给出
   当次证据时，发布状态只能是「阻塞」。
4. 本检查单由稳健性线创建；`reports/README.md` 与 `dev-docs/README.md` 的索引更新
   不在本线白名单内，交由整理代理补录。
5. 安全复查的通过条件（硬性）：
   - 渗透报告 must 无 **CRITICAL**；
   - 所有 **HIGH** 必须已登记 **owner + 截止日**（见 §6.3 表），否则不得勾选；
   - 审计日志缺口（MEDIUM）必须登记为发布 Blocker 或明确的后续修复线。
