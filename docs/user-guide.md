# 用户手册（训导员使用指南）

> 工作犬训练机器视觉识别系统 — Phase 3
> 适用版本: v0.3.0
> 目标用户: 工作犬训导员 / 犬只管理人员 / 基地管理员 / 系统管理员
> 访问地址: http://127.0.0.1:5173（前端） / http://127.0.0.1:8000/docs（API 文档）

## 1. 系统概述

### 1.1 系统用途

本系统基于机器视觉技术，对工作犬训练视频进行自动分析，输出客观的评分报告。当前支持四类场景：

| 场景 | 中文名 | 适用阶段 | 评分维度 | 行为识别 | 输出 |
|------|--------|---------|---------|---------|------|
| `obedience_trial` | 科目测评 | 训练中/考核 | 5 维（准确度/延迟/保持/注意力/步态） | P0 8 类 | PDF 评分报告 |
| `puppy_selection` | 幼犬选育 | 幼犬筛选 | 3 维（食物欲望/猎物欲望/胆量） | 物体检测 | PDF 评分报告 |
| `uspca_patrol` | USPCA 巡逻犬 | 巡逻犬认证 | 5 维（准确度/延迟/保持/搜索效率/注意力） | P0+P1 16 类 | PDF 评分报告 |
| `fci_igp` | FCI-IGP 国际工作犬 | 国际认证（IGP1/IGP2/IGP3） | 7 维（准确度/延迟/保持/搜索效率/注意力/胆量/步态） | P0+P1+P2 22 类 | PDF 评分报告（Phase 3 新增） |

### 1.2 核心能力

- **24 关键点姿态检测**：基于 YOLO26-pose 微调模型，识别犬只全身 24 个关键点
- **22 类行为识别**（Phase 3 扩展，双轨并行 SHADOW 模式）：
  - P0 基础 8 类：坐 / 卧 / 立 / 随行 / 坐立 / 停留 / 叫 / 咬
  - P1 训练专项 8 类：追踪 / 示警坐 / 示警卧 / 扑咬 / 押解 / 障碍穿越 / 返回 / 警戒
  - P2 高级 6 类（Phase 3 新增）：拒绝食物 / 拒绝捡拾 / 远距离指挥 / 嗅闻搜索 / 跃过障碍 / 静默警戒
  - 双轨机制：ST-GCN+BC 深度学习模型（合成 baseline 46.97%，待真实数据训练升级）+ 规则引擎并行，SHADOW 模式对比验证
- **3D 姿态重建**（Phase 3 新增）：MotionBERT-Lite 2D-to-3D lifting，MPJPE=21.74mm，提升行为识别精度
- **多犬追踪**（Phase 3 新增）：BoxMOT + OccluBoost + ReID 身份关联，支持多犬同时测评
- **物体检测**（选育场景）：球类 / 食物 / 玩具 / 人 / 犬
- **9 信号提取**（选育场景）：接近延迟 / 接近速度 / 嗅闻时长 / 追逐延迟 / 追逐速度 / 衔持时长 / 退避距离 / 僵直时长 / 恢复时间
- **YAML 评分卡**：训导员可修改评分规则，热加载生效，无需重启
- **PDF 报告**：自动生成评分报告，可下载/打印
- **数据飞轮**（Phase 2 新增）：上传 → 标注 → 微调 → 部署闭环
- **历史评分查询**（Phase 2 新增）：按犬只查询历史评分记录
- **训练历史对比可视化**（Phase 3 新增）：多犬只训练趋势对比 + 7 维雷达图 + 统计摘要
- **RBAC 多角色权限**（Phase 3 新增）：5 角色（系统管理员/基地管理员/训导员/观察员/审计员）+ 基地隔离 + 多租户

### 1.3 系统架构（简化）

```
[训导员浏览器] ←→ [前端 Vue] ←→ [FastAPI 后端 + RBAC 鉴权]
                                      ↓
                              [Celery Worker]
                                  ↓     ↓     ↓     ↓
                          [YOLO26-pose] [ST-GCN+BC] [MotionBERT] [评分引擎]
                              ↓             ↓           ↓
                          [多犬追踪]    [行为识别]  [3D 姿态]
                                  ↓
                          [PDF 报告生成]
```

## 4. 上传视频（核心流程）

### 4.1 准备视频

**格式要求**：
- 文件格式：.mp4 / .avi / .mov / .mkv / .webm
- 文件大小：≤ 2 GB
- 视频时长：建议 10 秒 - 5 分钟
- 分辨率：建议 480p 及以上
- 帧率：建议 25-60 FPS

**拍摄建议**：
- 单犬场景为主；FCI-IGP 场景支持多犬同时测评（Phase 3 BoxMOT + ReID 身份关联）
- 光线充足，避免逆光
- 摄像机固定或缓慢移动
- 犬只全身入镜，无遮挡

### 4.2 上传步骤

1. 点击左侧菜单 **"上传视频"**
2. **选择场景**：
   - `科目测评`：训练中/考核场景（坐/卧/立/随行等指令行为）
   - `幼犬选育`：幼犬筛选场景（食物/玩具/胆量测试）
   - `USPCA 巡逻犬`：巡逻犬认证场景（16 行为 + 5 维评分，Phase 2 新增）
   - `FCI-IGP 国际工作犬`：国际工作犬认证场景（22 行为 + 7 维评分 + IGP1/IGP2/IGP3 三阶段，Phase 3 新增）
3. **选择犬只**（可选）：从下拉框选择已录入的犬只档案；若无则选择"未关联"
4. **拖拽视频** 到上传区域，或点击区域选择文件
5. 确认信息无误后，点击 **"开始上传"**
6. 上传完成后，页面自动跳转到 **报告详情页**

### 4.3 处理状态

上传后系统进入异步处理，状态变化：

| 状态 | 含义 | 预期耗时 |
|------|------|---------|
| `pending` | 已入库，等待 Worker 接收 | < 5 秒 |
| `processing` | 推理中（姿态/行为/物体/评分） | ≤ 1 分钟/分钟视频 |
| `completed` | 处理完成，PDF 已生成 | - |
| `failed` | 处理失败，查看错误信息 | - |

**实时轮询**：报告页每 3 秒自动刷新状态，无需手动刷新。

## 5. 查看报告

### 5.1 报告详情页

处理完成后，报告页显示：

- **视频信息**：文件名 / 时长 / 帧率 / 分辨率 / 上传时间
- **犬只信息**（如已关联）：名字 / 品种 / 性别 / 芯片号 / 训练阶段
- **评分总览**：
  - 总分（0-100）
  - 判定结果：`合格` / `基本合格` / `不合格`
  - 各维度分数进度条
- **PDF 预览**：内嵌浏览器 PDF 预览，可下载/打印

### 5.2 评分维度说明

#### 科目测评（5 维）

| 维度 | 权重 | 信号来源 | 含义 |
|------|------|---------|------|
| 准确度 | 0.30 | `action_correct / action_count` | 指令执行正确率 |
| 延迟 | 0.20 | `command_to_action_latency` | 从指令到行为响应的延迟 |
| 保持 | 0.20 | `action_duration` | 行为持续时间 |
| 注意力 | 0.15 | `focus_ratio` | 犬只注意力集中度 |
| 步态 | 0.15 | `gait_score` | 随行步态质量 |

#### 幼犬选育（3 维）

| 维度 | 权重 | 信号来源 | 含义 |
|------|------|---------|------|
| 食物欲望 | 0.40 | `approach_latency` / `approach_speed` / `sniff_duration` | 接近食物的速度与嗅闻时长 |
| 猎物欲望 | 0.40 | `chase_latency` / `chase_speed` / `hold_duration` | 追逐玩具/球的速度与衔持时长 |
| 胆量 | 0.20 | `retreat_distance` / `recovery_time` / `freeze_duration` | 面对陌生刺激的退避距离与恢复时间 |

#### USPCA 巡逻犬认证（5 维，Phase 2 新增）

| 维度 | 权重 | 信号来源 | 含义 |
|------|------|---------|------|
| 准确度 | 0.30 | `action_correct / action_count` | 指令执行正确率（confidence ≥ 0.80 视为正确） |
| 延迟 | 0.20 | `command_to_action_latency` | 指令到动作响应时间（USPCA > 3 秒扣分） |
| 保持 | 0.20 | `action_duration` | 动作保持时间（USPCA < 5 秒扣分） |
| 搜索效率 | 0.15 | `search_coverage` / `search_speed` / `target_found` | 搜索覆盖率 + 速度 + 目标发现 |
| 注意力 | 0.15 | `focus_ratio` / `unnecessary_movement_count` | 注意力聚焦 + 不必要移动控制 |

**USPCA 16 行为映射**：
- P0 服从基础：sit / down / stand / heel / sit_up / stay / bark / bite
- P1 巡逻专项：track（追踪）/ alert_sit（示警坐）/ alert_down（示警卧）/ apprehend（扑咬）/ escort（押解）/ obstacle（障碍穿越）/ recall（返回）/ watch（警戒）

#### FCI-IGP 国际工作犬认证（7 维，Phase 3 新增）

| 维度 | 权重 | 信号来源 | 含义 |
|------|------|---------|------|
| 准确度 | 0.25 | `action_correct / action_count` | 指令执行正确率（IGP 标准更严，confidence ≥ 0.85 视为正确） |
| 延迟 | 0.15 | `command_to_action_latency` | 指令到动作响应时间（IGP > 2 秒扣分） |
| 保持 | 0.15 | `action_duration` | 动作保持时间（IGP < 5 秒扣分） |
| 搜索效率 | 0.15 | `search_coverage` / `search_speed` / `target_found` | 搜索覆盖率 + 速度 + 目标发现（追踪 + 嗅闻搜索） |
| 注意力 | 0.10 | `focus_ratio` / `unnecessary_movement_count` | 注意力聚焦 + 不必要移动控制 |
| 胆量 | 0.10 | `courage_score` / `avoidance_detected` | 面对刺激的胆量表现 + 退避检测（扑咬 + 静默警戒场景） |
| 步态 | 0.10 | `gait_symmetry` / `pace_change_smoothness` | 步态对称性 + 步伐变化平滑度（随行 + 障碍穿越场景） |

**FCI-IGP 22 行为映射**：
- P0 基础 8 类：sit / down / stand / heel / sit_up / stay / bark / bite
- P1 训练专项 8 类：track / alert_sit / alert_down / apprehend / escort / obstacle / recall / watch
- P2 高级 6 类（Phase 3 新增）：refuse_food（拒绝食物）/ refus_pickup（拒绝捡拾）/ remote_command（远距离指挥）/ scent_search（嗅闻搜索）/ jump_obstacle（跃过障碍）/ silent_watch（静默警戒）

**IGP 三阶段覆盖**：
- IGP1（入门）：4 行为（sit / down / heel / stay）
- IGP2（进阶）：12 行为（IGP1 + stand / bark / track / alert_sit / alert_down / recall / watch / obstacle）
- IGP3（高级）：22 行为（全部，含 P2 高级 6 类）

**DQ 硬约束（直接判定不合格）**：
- `avoidance_detected = True`：退避行为检测到
- `target_found = False`：搜索场景未发现目标
- `action_correct < 5`：正确行为数 < 5 次

**5 级评级**：
- Excellent（优秀）：≥ 90 分
- Very Good（良好）：80-89 分
- Good（合格）：70-79 分
- Satisfactory（基本合格）：60-69 分
- Insufficient（不合格）：< 60 分

## 6. 训练历史对比（Phase 3 新增）

### 6.1 进入对比页

点击左侧菜单 **"训练对比"**（StatsChartOutline 图标），进入对比页。

### 6.2 选择对比对象

1. **选择犬只**：在多选下拉框中选择 1-10 只犬进行对比（必选至少 1 只）
2. **选择评分标准**：
   - `obedience_trial`：科目测评
   - `uspca_patrol`：USPCA 巡逻犬
   - `fci_igp`：FCI-IGP 国际工作犬（默认）
3. **选择日期范围**（可选）：默认全部历史
4. 点击 **"生成对比"**

### 6.3 对比视图

对比页显示 4 个视图区域：

#### 6.3.1 趋势折线图（ECharts）

- **横轴**：评分时间（按上传日期排序）
- **纵轴**：评分总分（0-100）
- **每条线**：一只犬的训练趋势
- **交互**：鼠标悬停显示具体分数 + 日期；图例点击切换显示/隐藏

#### 6.3.2 7 维雷达图

- 多犬只 7 维评分均值对比（准确度/延迟/保持/搜索效率/注意力/胆量/步态）
- 雷达图覆盖区域大小反映综合能力
- 多边形颜色区分不同犬只

#### 6.3.3 统计卡片

每只犬显示：
- 平均分 / 最高分 / 最低分
- 评分次数
- 最近评分日期
- 标准差（评分稳定性）

#### 6.3.4 对比详情表

| 列 | 含义 |
|----|------|
| 犬只 | 名字（可点击跳转犬只档案） |
| 品种 | GermanShepherd / BelgianMalinois 等 |
| 评分次数 | 历史评分记录总数 |
| 平均分 | 所有评分的算术平均 |
| 最高分 / 最低分 | 历史评分极值 |
| 最近评分 | 最近一次评分的日期 + 总分 + 评级 |

### 6.4 对比场景应用

- **训导员复盘**：对比同一犬只不同时期的训练趋势，评估训练效果
- **基地管理员选犬**：对比多只候选犬只的 7 维能力，辅助选拔决策

### 8.2 评分卡配置（YAML 编辑器）

**核心功能**：在线编辑评分卡 YAML，修改后热加载生效。

#### 操作步骤

1. 选择场景（`puppy_selection` / `obedience_trial` / `uspca_patrol` / `fci_igp`）
2. YAML 编辑器显示当前评分卡内容
3. 修改规则 / 权重 / 阈值
4. 点击 **"保存"** → 系统校验 Schema → 写入文件 → 热加载
5. 用 **"试评分"** 功能验证修改效果

#### YAML 结构示例（选育评分卡）

```yaml
scoring_engine:
  name: "幼犬选育评分卡"
  version: "1.1.0"
  scene: "puppy_selection"
  dimensions:
    - id: food_drive
      name: "食物欲望"
      weight: 0.40  # 权重，所有维度之和必须 = 1.0
      rules:
        - id: food_high
          condition: "approach_latency < 1.0 and approach_speed > 2.0 and sniff_duration > 1.0"
          score: 90
          label: "高"
        # ... 更多规则
      default:      # 所有规则未命中时的默认分
        score: 40
        label: "中低"
  thresholds:
    pass: 70        # 合格线
    borderline: 60  # 基本合格线
    fail: 0         # 淘汰线
```

#### 修改建议

- **调整权重**：所有维度 `weight` 之和必须 = 1.0，否则 Schema 校验失败
- **修改阈值**：`pass` ≥ `borderline` ≥ `fail`
- **新增规则**：`id` 必须唯一；`condition` 表达式语法见下
- **规则顺序**：按顺序匹配，首个命中生效（`True` 作为兜底放最后）

#### 条件表达式语法

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `<` `>` `<=` `>=` `==` `!=` | 比较 | `approach_latency < 1.0` |
| `and` `or` | 逻辑与/或 | `a < 1 and b > 2` |
| `not` | 逻辑非 | `not (a > 5)` |
| `True` | 永真（兜底） | `condition: "True"` |

信号变量名见 §5.2 信号来源列。

#### 试评分

修改评分卡后，可输入一组信号值，立即查看评分结果，验证规则是否符合预期。

### 8.3 犬只档案管理

- **新增犬只**：点击"新增犬只"按钮，填写：
  - 名字（必填）
  - 品种（如 GermanShepherd / BelgianMalinois / Labrador）
  - 性别（公 / 母）
  - 芯片号（15 位数字）
  - 出生日期
  - 训练阶段（P0 / P1 / P2 / P3）
  - 训导员（可选）

  - 备注
- **编辑 / 删除**：列表行操作
- **搜索**：按名字 / 芯片号筛选
- **多犬关联**（Phase 3 新增）：同一训导员可关联多只犬，跨犬只训练对比见 §6

## 9. 典型工作流

### 9.1 训导员日常使用

```
1. 拍摄训练视频（手机/摄像机）
2. 登录系统 → "上传视频"
3. 选择场景（科目测评）→ 选择犬只 → 拖入视频
4. 等待处理完成（约 1 分钟/分钟视频）
5. 查看报告 → 7 维评分 + PDF
6. 下载 PDF 归档 / 打印汇报
```

### 9.2 选育评估工作流

```
1. 准备食物 / 玩具 / 陌生刺激物
2. 拍摄幼犬反应视频（建议 1-3 分钟）
3. 上传视频 → 选择场景（幼犬选育）
4. 系统自动检测物体 + 提取 9 信号
5. 查看 3 维评分（食物欲望/猎物欲望/胆量）
6. 根据评分决定是否进入训练体系
```

### 9.3 评分规则调整工作流

```
1. "系统管理" → "评分卡配置" Tab
2. 选择目标场景
3. 修改 YAML（如调整权重、新增规则）
4. 点击"保存" → Schema 校验通过
5. 用"试评分"验证规则效果
6. 上传新视频 → 新评分卡生效
```

### 9.4 USPCA 巡逻犬认证工作流（Phase 2 新增）

```
1. 拍摄巡逻犬训练视频（含服从 + 搜索 + 警戒场景，建议 1-3 分钟）
2. 登录系统 → "上传视频"
3. 选择场景（USPCA 巡逻犬）→ 选择犬只 → 拖入视频
4. 系统自动识别 16 行为（P0 8 类 + P1 8 类）
5. 查看 5 维评分（准确度/延迟/保持/搜索效率/注意力）
6. 下载 PDF 认证报告归档
```

### 9.5 数据飞轮工作流（Phase 2 新增，管理员）

数据飞轮实现"上传 → 标注 → 微调 → 部署"闭环，持续提升模型精度。

```
1. 上传视频到系统（正常流程）
2. 系统通过 AimCLR 预训练 + SMQ 时序分割自动生成行为 episode 边界
3. 主动学习不确定性采样选出最具信息量的 100-200 片段
4. 人工标注行为类别
5. 导出标注数据
6. 触发微调流水线（API: POST /api/finetune/trigger）
7. 训练完成，注册新模型版本（is_active=False）
8. 管理员在"系统管理 → 模型管理"激活新模型
9. 新视频自动使用新模型推理
```

### 9.6 FCI-IGP 国际工作犬认证工作流（Phase 3 新增）

```
1. 拍摄 FCI-IGP 训练视频（含 IGP1/2/3 三阶段对应行为，建议 2-5 分钟）
   - 多犬场景：可同时拍摄多只犬，系统通过 BoxMOT + ReID 自动区分身份
2. 登录系统 → "上传视频"
3. 选择场景（FCI-IGP 国际工作犬）→ 选择犬只 → 拖入视频
4. 系统自动识别 22 行为（P0 8 + P1 8 + P2 6）+ 3D 姿态重建 + SHADOW 双轨对比
5. 查看 7 维评分（准确度/延迟/保持/搜索效率/注意力/胆量/步态）+ 5 级评级
6. DQ 硬约束检测：退避/未发现目标/正确数 < 5 → 直接 Insufficient
7. 下载 PDF 认证报告归档（含 IGP 阶段标识）
```

### 9.7 训练历史对比工作流（Phase 3 新增）

```
1. 训导员/基地管理员登录系统 → "训练对比"
2. 选择 1-10 只犬（多选下拉框）
3. 选择评分标准（FCI-IGP 默认 / USPCA / 科目测评）
4. 选择日期范围（可选，默认全部历史）
5. 点击"生成对比" → 查看：
   - 趋势折线图（多犬只训练趋势对比）
   - 7 维雷达图（综合能力对比）
   - 统计卡片（平均分/最高分/最低分/标准差）
   - 对比详情表
6. 应用场景：训导员复盘 / 基地选犬决策 / 训练方法对比
```

1. 系统管理员创建基地 + 基地管理员账号
2. 基地管理员登录 → 创建训导员/观察员/审计员账号

## 10. 常见问题

### Q1: 上传后状态长时间停在 "processing"

**A**: 
- 检查 Celery worker 是否运行（系统管理 → 系统信息）
- 视频时长越长处理越久，预期 ≤ 1 分钟/分钟视频
- 首次上传有冷启动开销（约 10-15 秒加载模型）
- 若超过 5 分钟仍未完成，查看后端日志排查

### Q2: 评分为 0 或所有维度都 "未评估"

**A**: 
- 视频中犬只可能未检出（光线不足 / 遮挡 / 拍摄角度不佳）
- 信号值未触发任何规则，使用默认分
- 在"系统管理 → 评分卡配置"中检查规则条件是否过严

### Q3: PDF 报告无法下载

**A**:
- 检查 `reports/` 目录写入权限
- 浏览器拦截弹窗，允许该站点下载
- 后端日志查看 reportlab 报错

### Q4: 修改评分卡后评分没变化

**A**:
- 确认点击"保存"成功（应无红色错误提示）
- 热加载机制基于文件 mtime 检测，约 1 秒延迟
- 用"试评分"功能确认新规则生效
- 若用相同视频测试，需重新上传（旧评分结果不会自动更新）

### Q5: 视频上传失败 "413 Request Entity Too Large"

**A**:
- 文件超过 2 GB 限制
- 使用视频剪辑工具分割为多段
- 或修改 `backend/app/core/config.py` 中 `upload_max_size_mb`

### Q6: 如何修改评分卡中某个维度的权重？

**A**:
1. 系统管理 → 评分卡配置 → 选择场景
2. 找到目标维度（如 `food_drive`）
3. 修改 `weight` 值（0-1 之间小数）
4. **同步调整其他维度权重，确保总和 = 1.0**（否则保存失败）
5. 保存 → 试评分验证

### Q7: 系统支持哪些犬种？

**A**: Phase 1 MVP 使用 Dog-Pose 数据集微调，对常见工作犬种（德牧 / 马犬 / 拉布拉多 / 史宾格等）均有效。对非常见犬种（如玩具犬）关键点检测精度可能下降。

### Q8: 数据安全性如何保证？

**A**:
- Phase 1-3 严格本地化部署，无云依赖
- 数据不出本机（适用于公安/海关场景）
- 视频文件存储在 `data/uploads/`，PDF 报告在 `reports/`
- 数据库密码在 `.env` 中配置，不入 Git

## 11. 术语表

| 术语 | 含义 |
|------|------|
| 关键点 | 犬只身体上的特征点（鼻、眼、耳、肩、肘、腕、髋、膝、踝等），共 24 个 |
| 行为 episode | 一次完整的行为事件（如"坐下"从起拍到结束），含起止帧 + 置信度 |
| 信号 | 评分引擎的输入变量（如 `approach_latency` 接近延迟） |
| 评分卡 | YAML 配置文件，定义评分维度 / 规则 / 阈值 |
| 热加载 | 修改 YAML 后无需重启服务即生效 |
| 场景 | 评分场景类型（科目测评 / 幼犬选育 / USPCA 巡逻犬 / FCI-IGP 国际工作犬） |
| P0 行为 | 基础服从行为 8 类：坐/卧/立/随行/坐立/停留/叫/咬 |
| P1 行为 | 训练专项行为 8 类：追踪/示警坐/示警卧/扑咬/押解/障碍穿越/返回/警戒（Phase 2） |
| P2 行为 | 高级行为 6 类：拒绝食物/拒绝捡拾/远距离指挥/嗅闻搜索/跃过障碍/静默警戒（Phase 3） |
| 数据飞轮 | 上传→标注→微调→部署的闭环流程，持续提升模型精度（Phase 2） |
| USPCA | United States Police Canine Association，美国警犬协会巡逻犬认证标准（Phase 2） |
| FCI-IGP | Fédération Cynologique Internationale Internationale Gebrauchshund Prüfung，国际工作犬认证标准，IGP1/2/3 三阶段（Phase 3） |
| SHADOW 双轨 | ST-GCN+BC 深度学习模型 + 规则引擎并行推理对比模式（Phase 3） |
| ST-GCN+BC | Spatial-Temporal Graph Convolutional Network + Boundary Classification，时空图卷积 + 边界分类联合训练模型（Phase 3） |
| MotionBERT | 基于 Transformer 的 2D-to-3D 姿态 lifting 模型，用于 3D 姿态重建（Phase 3） |
| BoxMOT | 开源多目标追踪框架，集成 OccluBoost/BoT-SORT/ByteTrack 等追踪器（Phase 3） |
| ReID | Re-Identification，跨镜头身份重识别，用于多犬身份关联（Phase 3） |
| MPJPE | Mean Per Joint Position Error，3D 姿态重建精度指标，本项目 21.74mm（Phase 3） |
| RBAC | Role-Based Access Control，基于角色的访问控制，5 角色多租户权限（Phase 3） |
| 基地隔离 | 多租户数据隔离机制，不同基地数据完全隔离，仅系统管理员可跨基地查询（Phase 3） |
| DQ | Disqualification，FCI-IGP 硬约束直接判定不合格（退避/未发现目标/正确数 < 5）（Phase 3） |
| Celery Worker | 后台异步任务执行进程 |
| ONNX Runtime | GPU 推理后端（Phase 1 生产推荐） |
| Label Studio | 开源数据标注平台（已废弃，2026-08-19，改为主动学习管线，见 ADR 0012） |
